# 6차 연속 데이터 연구

새 자료 수집·GPU 학습·시간순 검증을 자동으로 연결하고 기존 모델의 업비트 현물 모의매매는 별도로 유지하는 차수입니다. 초기 50GB 연구 이후 매번 사용자의 요청을 기다리던 4차 정책을 연속 반복 방식으로 변경합니다.

## LEVEL 1 - Beginner

### LEVEL 1 · 이 자료가 하는 일과 달라진 점

새 자료 수집·GPU 학습·시간순 검증을 자동으로 연결하고 기존 모델의 업비트 현물 모의매매는 별도로 유지하는 차수입니다. 초기 50GB 연구 이후 매번 사용자의 요청을 기다리던 4차 정책을 연속 반복 방식으로 변경합니다.

### LEVEL 1 · 실제 동작을 따라 읽기

새 자료 수집·GPU 학습·시간순 검증을 자동으로 연결하고 기존 모델의 업비트 현물 모의매매는 별도로 유지하는 차수입니다. 초기 50GB 연구 이후 매번 사용자의 요청을 기다리던 4차 정책을 연속 반복 방식으로 변경합니다.

자료 준비 시간·공식 공개 주기·API 제한·오류 재시도·디스크 여유 검사는 필요합니다. 성공한 회차 뒤 임의의 휴식 시간을 추가하지 않는 것과 이러한 보호 장치를 제거하는 것은 다릅니다. 공식 고유 자료가 부족하면 수집 대기이며 같은 파일을 다시 받아 용량을 채우지 않습니다.

2GB는 고유 아카이브 수집 목표의 증가량입니다. 파일 단위 적재이므로 마지막 파일만큼 초과할 수 있습니다. 준비된 자료가 선행 한도에 도달하면 과거 수집은 대기하지만, 최근 분봉 누락·최신성 부족은 기존 제한된 일별·월별 klines 복구 계획으로 보완합니다. 이 복구를 별도 새2GB 달성으로 꾸미지 않습니다.

현재 검증 모델의 모의 판단은 수집·학습과 독립적으로 계속됩니다. 실제 주문·공매도·레버리지·외부 알림은 없습니다. 검증 거래 0건을 성공으로 바꾸거나 거래 횟수를 채우기 위해 정책을 강제하지 않습니다. 전체 정확도와 중립 기준선·Macro F1·비용 차감 수익·거래 표본을 구분합니다. 연속 학습은 성능·수익 보장이 아닙니다.

체크섬은 받은 바이트가 형식상 손상되지 않았는지 대조하는 값입니다. 모의 운용은 계산상 계좌와 거래를 다루므로 실제 계좌 체결과 구분합니다.

입력 — 고유 적재량·새 자료 2GB 목표·research.continuous

처리 — 새 자료 수집 → 준비 조건 확인 → GPU 연구 → 시간순 검증 → 다음 목표

출력 — 연속 연구 상태·확률/신호/거래 진단·검증 후보

### LEVEL 1 · 준비하고 확인할 것

requirements와 engine-config.json, CUDA·GPU·DB 및 자료 저장 경로를 확인합니다. 실제 거래 계정·운영 DB·모델·개인 로그는 공개 코드와 별도입니다. 외부 수집에는 네트워크·디스크 여유·체크섬과 최신성 조건이 필요합니다.

연속 연구의 역사적 실행 계약을 설명합니다. 현재 학습 중지 경계는 9차 안내를 함께 확인하며 사용자 명시 재개 없이 새로운 적합을 시작하지 않습니다.

#### LEVEL 1 · 실행 흐름

1. 완료된 연구 뒤 실제 고유 적재량을 확인하고 새 자료 2GB를 더하는 목표를 하나만 생성합니다.
2. 수집기는 원본 체크섬과 내용·시간 순서를 검증한 뒤 적재합니다. 중복 다운로드를 새로운 자료로 세지 않습니다.
3. 목표와 최근 분봉 준비 조건이 충족되면 GPU 후보 연구를 실행합니다. 학습 중 수집은 다음 자료를 최대 2GB까지 선행 준비합니다.
4. 학습·확률 보정·정책 선정·후속 평가를 분리하고, 검증 결과가 부족하면 모델을 교체하지 않습니다.
5. 연구 완료 뒤 최신 실제 적재량에서 다시 새 2GB 목표를 생성합니다. 선행 수집분을 이후 추가 2GB로 중복 계산하지 않습니다.

연속 모드는 `engine-config.json`의 `research.continuous`로 명시하며 기본값은 false입니다. 기존 수동 요청 모드와 상태 이력은 보존합니다. 사용자 중단 요청이 있으면 프로젝트의 수집·학습·모의매매를 중지하며 공유 컨테이너나 다른 연구는 중지하지 않습니다.

새 요청의 중복 생성은 별도 수집 할당 잠금으로 막고, 대용량 원본 검증은 연구 상태 잠금 밖에서 수행합니다. 자료를 검증하는 동안에도 학습 작업자는 준비 상태와 중단을 확인할 수 있습니다.

1. research.continuous의 기본값 false와 이 차수의 연속 모드 계약을 읽습니다.
2. 완료된 연구 뒤 실제 적재량에 새 고유 자료 2GB를 더하는 목표를 확인합니다.
3. 학습 중 수집은 다음 자료 최대 2GB를 선행 준비하고 이미 받은 자료를 다시 새 목표로 세지 않습니다.
4. 확률 보정·정책 선정·후속 평가와 기존 모의매매를 분리해 확인합니다.

### LEVEL 1 · 결과와 주의할 범위

자료 크기·고유 아카이브 크기·DB 크기를 구분하고 준비/학습/승격 상태를 함께 확인합니다. 모의 손익은 실제 주문 성과가 아닙니다. GPU 사용률·처리량 개선도 수익 개선과 별개입니다.

**상황:** 연구가 대기함

**확인할 내용:** 자료량·최근 분봉 커버리지·최신성·GPU 사전 조건을 확인합니다. 대기 상태를 임의 학습 성공으로 바꾸지 않습니다.

**상황:** 외부 자료 검증 실패

**확인할 내용:** 공식 아카이브·체크섬·원문 체결 형식·완료봉을 확인합니다. 보간이나 기존 봉 덮어쓰기로 우회하지 않습니다.

**상황:** 차수 폴더만 실행할 수 없음

**확인할 내용:** 루트 공통 엔진·설정·검사와 차수 연결 파일의 실제 import 경로를 확인합니다.

자료 준비 시간·공식 공개 주기·API 제한·오류 재시도·디스크 여유 검사는 필요합니다. 성공한 회차 뒤 임의의 휴식 시간을 추가하지 않는 것과 이러한 보호 장치를 제거하는 것은 다릅니다. 공식 고유 자료가 부족하면 수집 대기이며 같은 파일을 다시 받아 용량을 채우지 않습니다.

5. 연구 완료 뒤 최신 실제 적재량에서 다시 새 2GB 목표를 생성합니다. 선행 수집분을 이후 추가 2GB로 중복 계산하지 않습니다.

자료 준비 시간·공식 공개 주기·API 제한·오류 재시도·디스크 여유 검사는 필요합니다. 성공한 회차 뒤 임의의 휴식 시간을 추가하지 않는 것과 이러한 보호 장치를 제거하는 것은 다릅니다. 공식 고유 자료가 부족하면 수집 대기이며 같은 파일을 다시 받아 용량을 채우지 않습니다.

2GB는 고유 아카이브 수집 목표의 증가량입니다. 파일 단위 적재이므로 마지막 파일만큼 초과할 수 있습니다. 준비된 자료가 선행 한도에 도달하면 과거 수집은 대기하지만, 최근 분봉 누락·최신성 부족은 기존 제한된 일별·월별 klines 복구 계획으로 보완합니다. 이 복구를 별도 새2GB 달성으로 꾸미지 않습니다.

### 모델과 모의매매

현재 검증 모델의 모의 판단은 수집·학습과 독립적으로 계속됩니다. 실제 주문·공매도·레버리지·외부 알림은 없습니다. 검증 거래 0건을 성공으로 바꾸거나 거래 횟수를 채우기 위해 정책을 강제하지 않습니다. 전체 정확도와 중립 기준선·Macro F1·비용 차감 수익·거래 표본을 구분합니다. 연속 학습은 성능·수익 보장이 아닙니다.

중립 진단은 학습에 실제 반영된 클래스별 가중치 비중과 학습·튜닝·보정 전후 확률을 나눠 기록합니다. 학습 재대입 진단은 최근 최대2048행으로 제한하고 평가 성능으로 취급하지 않습니다. 기존 연구 후보 순환을 계속하며 신호를 늘리기 위해 매매 기준을 일괄 낮추지 않습니다.

연속 모드는 `engine-config.json`의 `research.continuous`로 명시하며 기본값은 false입니다. 기존 수동 요청 모드와 상태 이력은 보존합니다. 사용자 중단 요청이 있으면 프로젝트의 수집·학습·모의매매를 중지하며 공유 컨테이너나 다른 연구는 중지하지 않습니다.

새 요청의 중복 생성은 별도 수집 할당 잠금으로 막고, 대용량 원본 검증은 연구 상태 잠금 밖에서 수행합니다. 자료를 검증하는 동안에도 학습 작업자는 준비 상태와 중단을 확인할 수 있습니다.

## 처리 결과와 출력 읽기

자료 크기·고유 아카이브 크기·DB 크기를 구분하고 준비/학습/승격 상태를 함께 확인합니다. 모의 손익은 실제 주문 성과가 아닙니다. GPU 사용률·처리량 개선도 수익 개선과 별개입니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

**상황:** 연구가 대기함

**확인할 내용:** 자료량·최근 분봉 커버리지·최신성·GPU 사전 조건을 확인합니다. 대기 상태를 임의 학습 성공으로 바꾸지 않습니다.

**상황:** 외부 자료 검증 실패

**확인할 내용:** 공식 아카이브·체크섬·원문 체결 형식·완료봉을 확인합니다. 보간이나 기존 봉 덮어쓰기로 우회하지 않습니다.

**상황:** 차수 폴더만 실행할 수 없음

**확인할 내용:** 루트 공통 엔진·설정·검사와 차수 연결 파일의 실제 import 경로를 확인합니다.
