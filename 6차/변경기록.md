## 확인과 한계

신규 제어 회귀8개는 Linux에서 통과했고, 독립 예비 검토 뒤 STOP·bootstrap 선행 한도·설정 loader 회귀를 추가했습니다. 수정 전 미구현·설정 거부를 재현했고, 선행 수집 목표가 학습 준비량까지 올리는 추가 결함은 같은 목표 분리 assert의 실패 후 수정했습니다. 설정 loader에 연속 키를 빠뜨린 통합 실패와 새 검사에 과거 원금을 잘못 입력한 fixture 실패도 보존하고 기존 승인1000만원을 유지했습니다. 실제 파일 무결성·98% 최근 분봉·CUDA 전용 적합·검증 수익과 거래 표본·기존 모델 비교를 완화하지 않습니다.

중립 원인 진단에서 기존 후보는 이미 제한된 클래스 가중치를 사용했습니다. BTC·SOL의 정책 선정 단계 적격과 이후 중립 편향, DOGE의 방향 예측과 비용 차감 손실을 구분했습니다. 정책이 무조건 중립을 선택하는 결함은 확인되지 않아 임계값·후보 순서·승격 기준은 바꾸지 않았습니다. 새 진단은 다음 정규 연구부터 기록되며 과거 보고서를 다시 작성하지 않습니다.

Linux 검사에는 기존 NumPy generic timedelta 폐기 경고가 출력됩니다. 경고를 숨기거나 해결했다고 주장하지 않습니다. 통제된 회귀 통과와 실제 신규 연구 완료·수익성 개선은 별개입니다. 중립 편향과 거래 부족이 해결됐다고 단정하지 않으며 새 자료 기반 후보를 계속 검증합니다.

운영 배포에서 원본 재해시가 연구 상태 잠금을 오래 점유하는 실패를 확인했습니다. 별도 수집 할당 잠금과 짧은 연구 상태 잠금을 분리하여 느린 원본 검증 중에도 학습 상태 조회가 가능하도록 수정하고 병렬 조회 회귀를 추가했습니다. 공개 검토의 GPU 비교 링크 대응과 설정 파일 포함 안내도 실제 공개 구성에 맞췄습니다. 과거 실패와 최초 검토 결과는 비공개에 보존하며 이후 성공으로 덮어쓰지 않습니다.
