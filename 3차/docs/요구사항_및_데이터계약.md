# 3차 외부 대용량 자료 연구

## 최신 정정

같은 날 후속 사용자 요청으로 아래 초기30GB목표와자료준비중기본학습계속조건은대체됩니다. 최종흐름은외부고유아카이브50,000,000,000바이트다운로드·검증·청크처리완료→GPU초기학습→이후업비트요청당200개새봉을중복없이누적하며재학습입니다. 진행중인기존학습회차는정상종료하고다음새학습은50GB준비를기다립니다. 모의매매·기존포지션청산은항상별도진행합니다. 같은50GB를매회다시다운받거나최근200개만으로모델을덮어쓰지않습니다. 외부특징모델에필요한최신보조시세도계속갱신합니다.

`training_ready`는단순범위조건이아니라SHA검증과적재를마친고유아카이브`ingested_archive_bytes`50GB이상및5종목최신성·최근14일98%이상완성분봉을모두만족해야합니다. `verified_archive_bytes`와`ingested_archive_bytes`를구분하고후자가학습시작조건입니다. 실제압축파일하나의크기만큼목표를초과할수있으며기존디스크여유20GB경계는유지합니다. `external.wait_for_dataset=true`이면조건미달시trainer는실측다운로드상태를남기며유한간격폴링하고학습호출·가짜성공회차·오류폭주를만들지않습니다. false인기존설정과구manifest는호환합니다. 아래이전요구기록은삭제하지않으며충돌시이절이우선합니다.

확인일2026-10-30. 사용자는 새 차수에 외부 거래소 자료 약30GB를 모아 GPU 학습을 확대하고 업비트 현물 모의매매를 이어가기를 요청했습니다. 기존 보존 대응표에1차·2차를 확인했으며 이번3차는 이전 결과를 덮어쓰지 않습니다.

## 경계

실제 주문·외부 알림·계좌 초기화·공유 컨테이너 재시작은 하지 않습니다. 정확도100% 또는 수익은 보장하지 않으며 전체표본 정확도·다수클래스 기준선·MacroF1·시간순 후속평가·비용 차감 손익으로만 판정합니다. 기존 중립·승격·손실·출금 불가·잠금 시험 조건을 유지합니다. 데이터 파일30GB 자체는 성능 지표가 아닙니다.

새 자료는3차/work 아래에만 저장합니다. 기존 업비트 DB·계좌·모델은 부모프로젝트work를 이어 사용하며 복사하거나 초기화하지 않습니다. 데이터수집작업은 기존학습·모의매매를방해하지않는별도프로세스입니다. GPU개선까지의부모engine.py를보존하고공유연결지점만최소수정합니다.

## 외부 자료

Binance Vision의공식 spot monthly/daily klines 및 aggTrades 아카이브를 사용합니다. BTCUSDT·SOLUSDT·ETHUSDT·XRPUSDT·DOGEUSDT와 업비트 KRW5종목 대응은 고정합니다. 원화 가격으로 둔갑시키거나 레코드를 출처 구분 없이 기존 candles에 넣지 않습니다. 공개키 없이 시장자료 GET만 허용하고 실제주문 API는 사용하지 않습니다.

수집 목표는 검증한 압축아카이브30,000,000,000바이트이며 복제·압축해제중복·DB인덱스로 용량을 채우지 않습니다. 실제 확보량·검증된 고유 파일 수·고유분봉수·학습행수는 별개입니다. 파일을30GB이상메모리에동시에적재하지않고ZIP을스트리밍청크로집계합니다. 가용디스크최소20GB여유를남기며파일별유한재시도와HTTP404·429·5xx를구분합니다. 오래된파일갱신이가능하므로SHA256 CHECKSUM을검증하고원본/출처/단위/기간을기록합니다.

Binance공식문서에2025이후spot아카이브의마이크로초변경이명시되어있습니다. 기존밀리초와구분해UTC로정규화하고완성분만저장합니다. 월간·일간중복은minutePK로중복학습하지않습니다. 원시체결은1분OHLCV/거래대금/체결수/주도매수대금을스트리밍집계하며이를실제학습특징에사용합니다. 원시파일용량을학습행수로부풀리지않습니다.

## 저장 계약

`3차/work/data/external.sqlite3`의`bars`:

`symbol TEXT, open_time INTEGER, open REAL, high REAL, low REAL, close REAL, volume REAL, quote_volume REAL, trade_count INTEGER, taker_quote_volume REAL, source TEXT, PRIMARY KEY(symbol,open_time)`.

open_time은UTC밀리초분시작정수이며완료시각은open_time+60000입니다. 가격·양수·OHLC·체결수·주도대금 범위를 검사합니다.0거래량봉은허용하되미래완성봉은저장하지않습니다. SQLite/WAL은Linux안에서만엽니다. 부모콜렉터가스키마와수집·정규화를소유합니다.

`3차/work/status.json`은`schema_version=1`, `training_ready`bool, `updated_at`UTC ISO, `verified_archive_bytes`, `target_archive_bytes`, `unique_minute_rows`, `markets`symbol별`rows,first_open_ms,last_open_ms`, `state`, `error`를 가집니다. 준비판정은5종목각각최소30일이상범위·최소20000완성분봉·최신봉5분이내·스키마일치입니다. 범위30일이연속30일을보장한다는뜻은아니며결측은특징결측으로남깁니다. 수집중에는기존기본학습을계속하며외부준비완료시다음회차부터외부특징을사용합니다. 수집오류는상태와로그로노출하고누락을성공으로숨기지않습니다.

## 학습 연결

준비판정 보완: 단순한 처음/끝 범위만으로 중간 공백을 준비완료로 처리하지 않도록 각 종목 최근14일의완성분봉98%이상도필요합니다. 이검사는symbol/open_time기본키범위별로조회하여전이력반복스캔을하지않습니다. 일봉/월봉아카이브가아직제공되지않았다는404는자료없음으로별도기록하며네트워크오류와구분합니다.

deep작업자는engine.py와3차/external_features.py,tests/test_external_features.py를소유합니다. 기본설정에external.enabled=`false|true|"auto"`, db_path/status_path를명시하며모든경로는프로젝트3차/work안에서검증합니다. auto는한학습회차시작에준비판정과true/false를동결해manifest에기록합니다. 기존manifest에설정이없으면기존92특징경로를유지합니다. true인데자료/스키마가손상되면명시적오류이며조용한기본모델대체는금지합니다.

외부1분봉의닫힌시각을UTC로맞춘뒤변화율·거래량비율·변동성·주도매수비율등가격단위가없는특징을과거방향으로결합합니다. USD/USDT가격을KRW정답이나체결가격으로쓰지않습니다. 외부가격수준자체는입력하지않습니다. 최신특징은외부자료가준비된최신닫힌분봉까지만사용합니다. 무제한forwardfill·미래시간결합·결측0채움금지. 튜닝/후속평가의고정분리와보호기간은유지합니다.

모의추론은manifest에동결한설정을따라동일한특징을사용합니다. 외부누락·오래됨이면신규매수보류사유를남기고기존손절/청산은계속합니다. 준비자료가충분해지기전기존92특징모델운용은계속합니다. 자동교체는기존정규학습과승격경계만통과하며강제적용은하지않습니다.
