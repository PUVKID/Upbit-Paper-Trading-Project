# 학습 중지와 거래 모델 재정비

## 현재 결정

자동 학습을 중지하고 기존 체크포인트·모의계좌·시세 자료를 보존합니다. 공개 시세 수집과 기존 적용 모델의 현물 모의매매는 독립 유지합니다. 추가 학습과 미검증 모델 승격은 수행하지 않습니다. 이번 차수는 새 모델의 성능 달성 보고가 아닙니다.

## 확인한 한계

8차는 같은 학습·튜닝 자료를 사용한 50스텝 적합 10회, 총 500스텝입니다. 최초·마지막 학습 손실은 약 4.522→3.839로 감소했지만 튜닝 손실은 약 7.453→8.106으로 증가했습니다. 과적합을 의심할 근거이며 수익 향상의 증거가 아닙니다. 8차에는 새 독립 평가나 거래 수익 검증이 없습니다.

7차의 별도 20개 평가 창에서는 상대 MAE가 약 0.210743%로 종가 유지 기준 0.204550%보다 나빴습니다. 방향 일치율 20%는 작은 표본의 예측 지표이지 거래 승률이 아닙니다. 해당 소비 구간을 다시 독립 시험으로 쓰지 않습니다. 거대 사전학습 시계열 모델이라는 이유만으로 업비트 거래 우위를 가정하지 않습니다.

## 권장 방향

1. **성과 기준부터 고정:** 정확도 100%가 아니라 거래 비용 차감 기대수익, 최대 낙폭, 회전율, 노출 시간과 불확실성을 함께 비교합니다. 사용자 선택은 균형형이며 최대 낙폭 목표는 10% 이내입니다. 이는 손실 상한 보장이 아니며 실제 위험 설정을 이번에 변경하지 않습니다. 보유 시간과 평가 기간은 별도 정의하고 수익 보장 목표를 설정하지 않습니다.
2. **손실 원인 분해:** 종목·시장 국면·진입 신호·청산 사유별 총수익과 수수료·슬리피지·호가 비용을 분리합니다. 과거 호가가 없는 구간은 시장 변동과 스프레드를 정확히 분리할 수 없다는 한계를 남깁니다. 거래 수만 늘리기 위해 임계값을 낮추지 않습니다.
3. **검증 구조 우선:** 학습·튜닝·확률 보정·정책 선택·후속 평가를 시간순으로 분리하고 라벨의 미래 구간이 경계를 넘지 않게 합니다. 여러 상승·하락·횡보 구간을 순차 평가하며, 최종 미사용 구간은 후보와 기준을 동결한 뒤 한 번만 사용합니다. 후보 탐색 횟수와 소비 구간을 기록합니다.
4. **적은 후보로 공정 비교:** 현금 보유, 매수 후 보유, 단순 추세 전략, 기존 GPU XGBoost, 동결 Chronos-2, 필요한 경우 제한적 미세조정 후보를 같은 시간·비용·위험 예산에서 비교합니다. 모델을 더 섞는 것은 별도 구간에서 순증가 효과가 확인될 때만 허용합니다.
5. **예측과 주문 분리:** 과거에 관측 가능한 가격·거래량·변동성·호가·다중 시간봉·거래소 간 상대 변화를 사용하되 각 자료의 실제 도착 시각을 지킵니다. 예측 수익 분포와 불확실성을 비용·손절 위험과 비교하는 매매 정책을 둡니다. 미래에 알 수 없는 공변량을 입력하지 않습니다. 거래하지 않는 선택도 유지합니다.
6. **독립 실시간 검증 뒤 적용:** 과거 성적만으로 승격하지 않습니다. 동결 후보의 실시간 모의 결과와 기존 모델을 비교하고 수익·낙폭·비용·표본 불확실성이 함께 기준을 충족할 때만 적용을 검토합니다. 기존 장부와 새 진단 계좌를 합치지 않습니다.

권장 작업 순서는 **손실 분해 → 검증 계약 동결 → 단순 기준선 비교 → 한 가지 변경씩 검증 → 실시간 모의 비교**입니다. 학습량·파일 크기·GPU 점유율은 거래 우위의 대리 지표로 사용하지 않습니다. 지금은 학습 중지 상태이며 이 계획은 새 적합을 승인하거나 실행하지 않습니다.

## 중지 경계

`work/service/TRAINING_PAUSED`가 있으면 엔진의 `trainer`와 `experiment` 명령은 적합에 진입하지 않고 사용자 요청 대기 상태를 갱신합니다. 이미 실행 중인 구버전 프로세스는 별도로 정확한 프로젝트·명령을 확인해 종료해야 합니다. `7차/work/STOP`과 `8차/work/STOP`은 각 독립 연구 실행을 차단합니다. 이 표식은 사용자의 명시적 재개 요청 없이 삭제하지 않습니다. 임의 Python 코드나 다른 프로젝트까지 막는 운영체제 보안 경계는 아닙니다.

수집기는 그대로 유지하므로 자료 용량은 계속 증가할 수 있습니다. 원본·모델·운영 기록 삭제는 이번 변경에 포함하지 않습니다. 화면 배치·테마·모의매매 정책·원금·수수료·실제 주문 금지 경계는 변경하지 않습니다.
