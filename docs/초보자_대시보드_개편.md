# PUVKID 투자 스튜디오

## 후속 확정

2026-10-26 같은 대화 후속 요청으로 도지코인(DOGE)을 추가합니다. 지원 범위는 BTC/SOL/ETH/XRP/DOGE 다섯 시장의 수집·학습·가상 매매이며 초기 원금 합계1,000만원과 기존 총 노출·손실·검증 기준은 바꾸지 않습니다. 기존 네 시장 요구는 이 추가 종목 결정으로 대체됩니다. 메뉴는 홈·학습·시장·거래로 바꿉니다. 다섯 종목을 표시하되 실제 기록이 없는 도지코인은 준비 중으로 표시하고 모델 검증을 우회하지 않습니다. 아래 시안의 네 종목 구성은 이전 설계 근거이며 최종 구현은 다섯 종목입니다.

2026-10-26 사용자 최신 요청: 기존 화면이 너무 복잡하므로 비트코인을 모르는 사람도 한눈에 이해하는 시각 중심 화면으로 바꿉니다. 사용자 이름은 PUVKID만 사용하고 제목의 모의 운용은 투자 스튜디오로 대체합니다. 실제 투자로 오인하지 않도록 가상 자금·실제 주문 없음 표시를 유지합니다. 다중 사용자 기능은 요청되지 않았으므로 계정이나 장부 분리는 새로 만들지 않습니다.

## 구성과 범위

기존 전체 자료를 한 화면에 노출하는 방법은 거부됐습니다. 단순 색상·글꼴 변경만으로는 과밀한 정보 문제가 남습니다. 따라서 단순 요약과 상세 화면을 분리하는 구조를 구현 방향으로 선택합니다. 이는 부모가 선택한 구현안이며 이미지 시안에 대한 사용자의 별도 승인으로 표현하지 않습니다.

첫 화면은 자금 금액·변화, 현금/코인 자산 비중의 실제 3D 그래픽, 현재 상태, 코인 네 개의 예측 그림, 학습 상태 한줄로 구성합니다. 계좌 추이·전문 진단·학습 지표·기록·데이터·호가 원문은 별도 상세 영역에 보존합니다. 코인 이름은 비트코인·솔라나·이더리움·리플로 표시합니다. 모델의 과거 후속평가 예측을 현재 미래 수익 예측이나 실제 매매 신호라고 표현하지 않습니다. 표본 수는 확률이 아니며 확률로 바꾸지 않습니다.

나눔고딕700·흰색·차콜·청록·코랄, 얇은 글래스 재질과 여백을 유지합니다. 장식 구체와 무의미한 3D 회전은 넣지 않습니다. 자산 비중은 account.cash/account.equity 및 실제 assets에서만 계산하고 미기록은 미기록으로 표시합니다.0값과100%현금도 정상 시각화합니다.3D 막대의 높이와 색은 데이터와 같은 범례를 사용합니다.

## 구현 계획

- 웹4파일만 수정합니다. 기존API와 노드 계약은 가능한 유지하고 기존 필터·탭·상세를 접근 가능하게 보존합니다.
- 기존 화면을 보존자료 압축본으로 남기며 활성 실행 경로는 D:/2026/자동매매 한곳입니다.
- 변경 전에 새 브랜딩·낮은 정보 밀도·상세 접근·자산3D 데이터 연결의 실패 검사를 남깁니다.
- 실제 상태API에 연결한1440/1024/390 화면에서 시각 검사와 캔버스 픽셀·모션·모바일·접근성·오류·미기록을 검사합니다.
- 학습·수집·모의판단을 중단하지 않고 웹 작업자만 배포합니다. 운영SQLite는 호스트에서 열지 않습니다.
- 독립 verifier는 구현 수정 없이113회귀·정적검사·별도브라우저 확인을 수행합니다. 검증 미달·거래0·점검지연은 숨기지 않습니다.
