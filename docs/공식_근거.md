# 공식 근거

2026-10-21 확인.

- 업비트 분봉: https://docs.upbit.com/kr/reference/list-candles-minutes — 조회당 최대 200개, UTC 캔들 시작 시각. 완료 시각을 계산한 뒤 정렬합니다.
- 업비트 요청 제한: https://global-docs.upbit.com/id/reference/rate-limits — 캔들 그룹 IP 공유 제한. 병렬 수집기의 합계 요청량을 제어합니다.
- 시계열 검증: https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html — 시간순 분할과 gap. 미래 지평이 경계를 넘는 라벨을 제거합니다.
- 누수 방지: https://scikit-learn.org/stable/common_pitfalls.html — 전처리와 모델 선정에 시험 데이터를 사용하면 평가가 낙관적으로 편향됩니다.
- XGBoost GPU: https://xgboost.readthedocs.io/en/stable/gpu/ — hist와 device=cuda를 지정하고 실제 부스터 설정도 확인합니다.
- 도커 Windows GPU: https://docs.docker.com/desktop/features/gpu/ — WSL2 Linux 컨테이너 GPU 전달. 이 컴퓨터의 사용 가능 여부는 별도 검사합니다.
