# 실제 3D 학습 장치

2026-10-28 사용자는 평면 이미지에 움직임을 주는 방식을 거부하고 독립 부품으로 구성한 실제 입체 모델, 단계별 조명과 색 변화, 생생한 움직임을 요구했습니다. 선택 시안의 유리 질감과 정보 배치는 유지하되 이전 문서의 PNG 평면 방식은 더 이상 적용하지 않습니다.

성공 조건은 실제 형상으로 구성한 다섯 코인 입력·자료 준비 장치·GPU·평가 렌즈·모델 검토 장치입니다. 장치별 조명은 실제 API의 running 상태와 features, fit, calibration/locked_test, complete 단계에 대응해야 합니다. 표시용 시간을 기준으로 단계를 임의 순환하지 않습니다. 부품과 이동 입자는 처리 흐름을 표현하며 처리량·진행률·실제 시세 그 자체가 아닙니다. 마지막 단계의 점등도 채택 성공이나 수익을 의미하지 않습니다.

각 장치는 독립 형상과 재질로 렌더링합니다. 환경 반사와 모서리 곡면을 사용하며, 실제 형상에 대한 그림자·빛·시점 변화를 유지합니다. 학습 개념도 전체를 담은 PNG 평면을 사용하지 않습니다. WebGL이 없는 경우 실제 문자 단계와 수치를 유지하고 3D 사용 불가를 표시합니다.

움직임 정지·운영체제 모션 줄이기·숨겨진 탭·화면 밖에서는 불필요한 연속 렌더링을 중단합니다. 화면 모션 정지는 학습·수집·모의매매의 정지가 아닙니다. 최대 24프레임, 픽셀 비율 1.25 이하로 제한합니다. 실제 엔진·DB·매매 기준·자금·컨테이너는 변경하지 않습니다.

검증은 실제 API 연결, 통제된 단계 변경에 따른 장치 점등·색 전환, 독립 부품 회전, 픽셀 변화, 모션 정지, 오류·미기록 상태, 두 테마와 모바일, 기존 필터와 홈 3D 회귀를 포함합니다. 통제된 표시 시험은 실제 운용 성과와 구분합니다.

공식 근거: https://threejs.org/docs/pages/MeshPhysicalMaterial.html 및 https://threejs.org/docs/pages/RoundedBoxGeometry.html . 물리 재질은 환경 맵을 사용하고 투과 효과 비용을 고려합니다.
