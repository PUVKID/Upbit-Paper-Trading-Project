# 🗂️ 차수별 독립 프로젝트 안내

## 11차 사전학습 모델 Zero-Shot 비교

유효 GPU 비교10회는 원7회+원계획 잔여2회+자료 부족 대체1회입니다. 추가학습0회·완료 후 중지·기존5코인 모의매매 유지를 구분합니다. 56,320처리창은 시장 예측56,300창과 재로드 확인20개이며, 후속 평가28,150방향표본의 가중 일치율은49.136767%입니다. 현금7회·거래 발생3회 모두 기본 비용에서 손실로 신규 후보를 적용하지 않았습니다. 방향 일치율을 승률로 바꾸거나 회차 수익을 연속 계좌의 누적으로 합산하지 않습니다.
