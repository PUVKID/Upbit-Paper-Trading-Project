# 기존 2026 컨테이너로 통합

2026-10-26 사용자는 별도로 만든 upbit-paper-research-v7 컨테이너를 삭제하고 기존 2026 컨테이너의 프로젝트 폴더를 직접 쓰도록 명시했습니다.

현재 채팅 제목은 앱 조회에서 앞 이모지를 포함한 Upbit 5-Coin Project로 확인했고, 폴더명은 앞 이모지만 제외한 Upbit 5-Coin Project입니다.

채팅 제목은 바꾸지 않습니다.

최종 호스트 root는 .

이며 컨테이너 root는/workspace/2026/Upbit 5-Coin Project입니다.

기존 2026의 D:/2026 bind mount를 그대로 사용하므로 소스·데이터를 별도 실행 폴더로 복제하지 않습니다.

다른 연구 파일·공용 환경·compose·컨테이너 자체는 변경하거나 삭제하지 않습니다.

## 이전 순서

도지코인 초기 수집이 끝난 뒤 기존 전용 서비스만 정상 종료하고 Linux에서 WAL 정리·무결성을 확인합니다.

모든 구현 작업자의 파일 동결과 임시 호스트 미리 보기 종료 후 경로의 실 주소가 D:/2026 하위인지 확인하고 프로젝트 폴더를 한 번만 이름 변경합니다.

운영 DB·장부·모델·실패 증거·원본은 보존합니다.

임의 장부 초기화나 4 종목 모델의 검증 우회는 하지 않습니다.

2026 내 프로젝트 .venv는 공용 패키지를 상속하되 프로젝트 의존성은 별도로 설치합니다.

별도 이미지나 연구 컨테이너를 생성하지 않습니다.

학습·수집·가상 판단·대시보드 서버는 2026 안에서 실행합니다.

호스트는127.0.0.1 한정 읽기 전용 화면 게이트 웨이만 실행하며 운영 SQLite는 열지 않습니다.

기존 2026에는 외부 포트가 없기 때문에 Docker exec를 통한 로컬 HTTP 릴레이를 사용하며 공용 컨테이너 재시작이나 다른 프로젝트 포트 설정을 요구하지 않습니다.

새 구조가 검증되면 전용 컨테이너·그 전용 이미지 태그·더 이상 사용하지 않는 Dockerfile과.dockerignore를 정리합니다. 실패·검증·데이터 이력은 불필요 파일로 일괄 삭제하지 않습니다. 예전 전용 실행 도구는 기존 2026 만 지원하도록 교체하고 실제 실행 root를 새 경로로 갱신합니다.

## 성공 조건

기존 2026의 ID와 시작 시각은 바뀌지 않습니다.

별도 upbit 컨테이너가 없고 프로젝트 root는 새 폴더한 곳입니다.

실제 GPU 확인·5 종목 공개 호가·45개 시간 봉 데이터·원금 합계 천 만 원·장부 연속성·신규 웹 화면·독립 검증을 확인합니다.

데이터 준비/수익 검증 미달은 그대로 표시하고 실제 체결 성공이나 수익을 조작하지 않습니다.
