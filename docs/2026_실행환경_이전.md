# 기존2026 컨테이너로 통합

2026-10-26 사용자는 별도로 만든 upbit-paper-research-v7 컨테이너를 삭제하고 기존2026 컨테이너의 프로젝트 폴더를 직접 쓰도록 명시했습니다. 현재 채팅 제목은 앱 조회에서 앞 이모지를 포함한 Upbit 5-Coin Project로 확인했고, 폴더명은 앞 이모지만 제외한 Upbit 5-Coin Project입니다. 채팅 제목은 바꾸지 않습니다.

최종 호스트 root는 D:/2026/Upbit 5-Coin Project이며 컨테이너 root는 /workspace/2026/Upbit 5-Coin Project입니다. 기존2026의 D:/2026 bind mount를 그대로 사용하므로 소스·데이터를 별도 실행 폴더로 복제하지 않습니다. 다른 연구 파일·공용환경·compose·컨테이너 자체는 변경하거나 삭제하지 않습니다.

## 이전 순서

도지코인 초기 수집이 끝난 뒤 기존 전용 서비스만 정상 종료하고 Linux에서 WAL 정리·무결성을 확인합니다. 모든 구현 작업자의 파일 동결과 임시 호스트 미리보기 종료 후 경로의 실주소가 D:/2026 하위인지 확인하고 프로젝트 폴더를 한 번만 이름 변경합니다. 운영 DB·장부·모델·실패 증거·원본은 보존합니다. 임의 장부 초기화나4종목모델의검증우회는하지않습니다.

2026 내 프로젝트 .venv는 공용패키지를 상속하되 프로젝트 의존성은 별도로 설치합니다. 별도 이미지나 연구 컨테이너를 생성하지 않습니다. 학습·수집·가상판단·대시보드 서버는2026 안에서 실행합니다. 호스트는127.0.0.1 한정 읽기 전용 화면 게이트웨이만 실행하며 운영 SQLite는 열지 않습니다. 기존2026에는외부포트가없기때문에Docker exec를통한로컬HTTP릴레이를사용하며공용컨테이너재시작이나다른프로젝트포트설정을요구하지않습니다.

새구조가검증되면 전용컨테이너·그전용이미지태그·더이상사용하지않는Dockerfile과.dockerignore를정리합니다. 실패·검증·데이터이력은불필요파일로일괄삭제하지않습니다. 예전 전용 실행 도구는 기존2026만 지원하도록 교체하고 실제 실행 root를 새 경로로 갱신합니다.
