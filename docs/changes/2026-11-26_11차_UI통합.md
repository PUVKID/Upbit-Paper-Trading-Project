현재 조회 UI는 E11의 8881 화면으로 교체한 기록을 사용합니다. 문서·테마·어댑터 HTTP200과 상태 API HTTP503을 구분하며 정상 시세 연결 성공으로 보고하지 않습니다. 제품·UI·Rust 검사는 기존 유효 근거를 재사용하고, 이번에는 공개 영향만 확인합니다.

`SOURCE`의 D relay 의존과 테마 생성기의 공통 E Rust 의존은 남습니다. 현재 공개 파일만으로 원래 실행 환경·데이터·공통 Rust 빌드 전체를 재현할 수 있다는 뜻이 아닙니다. 현재 소스의 개인 홈 동적 Python 탐색은 그대로 보존합니다. 학습·계좌·전략·인증·컨테이너·실주문·원래 결과는 변경하지 않았습니다.

현재 공개 기준은 `36431ba6997647f6e330901b791e67acc0bc3e1a`입니다. 최초 준비 기준은 `7eb008faa43f102ad634d09f68d615094cc3ec83`이며, 이후 원격 문서 변경을 병합해 현재 기준으로 정합했습니다. 보존된 과거 공개 검토는 그 당시 범위에 한정하며 최신 원격 안내와 이번 UI 통합을 과거 PASS로 승인하지 않습니다. 이 후보는 독립 공개 검토와 최종 반영이 남은 상태입니다.
