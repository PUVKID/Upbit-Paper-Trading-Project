### LEVEL 1 · 실제 동작을 따라 읽기

초기 고유 아카이브50,000,000,000바이트 준비 뒤 연구 한 회차, 완료 뒤 명시 요청마다 현재 적재량+2,000,000,000바이트를 제어합니다.

ResearchControl이 collecting→training→completed 상태와 batch ID·claim·attempt를 보존합니다.

결과 JSON·보고서·모델 해시를 요청과 결합해 저장 중단 뒤 동일 연구를 다시 적합하지 않고 남은 완료 처리를 복구합니다.

모의매매·최신 시세 갱신은 연구 수집·학습·명시 요청 대기와 독립적으로 유지됩니다.

체크섬은 받은 바이트가 형식상 손상되지 않았는지 대조하는 값입니다. 모의 운용은 계산상 계좌와 거래를 다루므로 실제 계좌 체결과 구분합니다.

입력 — 실제 고유 적재량·명시 추가 요청·다섯 시장 후보 학습 결과

처리 — 목표 동결 → 수집/준비 → 소유권 획득 → 결과 결합 저장 → 완료/복구

출력 — research_control.json·시도별 JSON·보고서/모델 해시·승격 여부

### LEVEL 1 · 준비하고 확인할 것

requirements와 engine-config.json, CUDA·GPU·DB 및 자료 저장 경로를 확인합니다. 실제 거래 계정·운영 DB·모델·개인 로그는 공개 코드와 별도입니다. 외부 수집에는 네트워크·디스크 여유·체크섬과 최신성 조건이 필요합니다.

이 차수 폴더만이 독립 실행 환경인지 먼저 확인합니다. 3차 외부자료 모듈과 4·5차 제어는 루트 engine.py·engine-config.json 및 tests와 연결됩니다. 실행 명령과 운영 경로는 해당 차수 README의 계약을 따릅니다.

#### LEVEL 1 · 정체 원인

적재량 7,067,731,134바이트와 체크섬 검증량 7,832,698,113바이트는 서로 다른 지표입니다. `BTCUSDT-aggTrades-2026-02.zip`은 공식 체크섬이 일치했지만 내부에 역행·중복된 체결 블록이 있었습니다. 기존 반복 재시도가 다음 정상 아카이브 처리를 막았습니다. 이 자료를 정렬·중복 제거하여 정상 원본으로 가장하거나 50GB 목표에 포함하지 않습니다.

수정본을 연구 제어 변경과 함께 배포하려다 기존 수집기의 정체를 오래 남겼습니다. 수집기 선배포 때에는 루트에서 실행한 모듈 검사와 실제 스크립트 진입점의 모듈 경로 차이로 시작 직후 종료되는 결함도 확인했습니다. 관리 명령의 PID 반환만으로 수집 정상 동작을 판정하지 않습니다. 실제 데이터 증가와 모의매매 판단 갱신을 별도로 확인합니다.

#### LEVEL 1 · 연구 요청·저장·실패 복구

`validate_config`는 `active`·`continuous`·`state_path` 외 설정을 거부하고 두 플래그는 정확한 bool을 요구합니다. 기본값은 `active=false`, `continuous=false`, `state_path=4차/work/research_control.json`입니다. 경로는 프로젝트의 `4차/work` 안 JSON으로 제한하고, 비활성 상태의 연속 연구는 거부합니다. `continuous` 코드 분기가 존재해도 이 차수의 두 트랙 계약은 초기 완료 후 명시 요청 대기입니다.

`request_increment`는 초기 학습 미완료·기존 활성 요청을 거부합니다. 요청을 받은 시점의 실제 고유 적재량을 baseline으로 읽고 2,000,000,000바이트를 더한 목표를 저장하므로, 이전 아카이브 단위 초과분을 다음 요청 분량으로 재사용하지 않습니다.

**함수·상태:** `_read`·`_validate`

**동작과 경계:** 첫 상태는 schema_version=1, bootstrap·collecting입니다. batch 필드, 비음수 정수, UTC 시각, ID·상태·완료 근거를 검증하고 JSON 중복 키를 거부합니다.

**함수·상태:** `training_lock`·상태 잠금

**동작과 경계:** 긴 적합 점유와 짧은 상태 읽기 잠금을 분리합니다. 상태 잠금은 최대30초,50ms 간격이며 학습 잠금은 비차단입니다.

**함수·상태:** `claim_training`

**동작과 경계:** collecting만 training으로 바꾸고 UUID claim과 attempts+1을 저장합니다.

**함수·상태:** `start_attempt`

**동작과 경계:** 요청·claim·시도·목표와 결과 폴더를 묶은 별도 시도 JSON을 만들며 기존 시도를 덮지 않습니다.

**함수·상태:** `record_model_failure`

**동작과 경계:** running 시도를 model_failed로 남기고 batch를 collecting으로 돌립니다. 오류 원문·시도 횟수는 보존합니다.

**함수·상태:** `store_result`

**동작과 경계:** 보고서 SHA·manifest SHA·모델 SHA와 batch 결합을 확인하여 complete 시도 결과를 원자 저장합니다.

**함수·상태:** `restore_claim`·`complete_training`

**동작과 경계:** 저장된 complete 결과를 검증하여 소유권과 완료 상태를 복구합니다. 완료 결과가 있는 시도를 무조건 재학습하지 않습니다.


`_atomic_write`는 UTF-8·LF·NaN 금지 JSON을 임시 파일에 쓰고 flush/fsync 후 교체합니다. 상태·시도 파일의 심볼릭 링크를 거부합니다. `_result`는 BTC·SOL·ETH·XRP·DOGE 다섯 시장의 후보 수, `cuda:` 장치, 준비 참, 목표 이상의 고유 적재/검증 바이트를 대조합니다. `promoted`는 학습 완료와 별도 bool로 기록합니다.

#### LEVEL 3 · 연구 요청·저장·실패 복구

`validate_config`는 `active`·`continuous`·`state_path` 외 설정을 거부하고 두 플래그는 정확한 bool을 요구합니다. 기본값은 `active=false`, `continuous=false`, `state_path=4차/work/research_control.json`입니다. 경로는 프로젝트의 `4차/work` 안 JSON으로 제한하고, 비활성 상태의 연속 연구는 거부합니다. `continuous` 코드 분기가 존재해도 이 차수의 두 트랙 계약은 초기 완료 후 명시 요청 대기입니다.

`request_increment`는 초기 학습 미완료·기존 활성 요청을 거부합니다. 요청을 받은 시점의 실제 고유 적재량을 baseline으로 읽고 2,000,000,000바이트를 더한 목표를 저장하므로, 이전 아카이브 단위 초과분을 다음 요청 분량으로 재사용하지 않습니다.

**함수·상태:** `_read`·`_validate`

**동작과 경계:** 첫 상태는 schema_version=1, bootstrap·collecting입니다. batch 필드, 비음수 정수, UTC 시각, ID·상태·완료 근거를 검증하고 JSON 중복 키를 거부합니다.

**함수·상태:** `training_lock`·상태 잠금

**동작과 경계:** 긴 적합 점유와 짧은 상태 읽기 잠금을 분리합니다. 상태 잠금은 최대30초,50ms 간격이며 학습 잠금은 비차단입니다.

**함수·상태:** `claim_training`

**동작과 경계:** collecting만 training으로 바꾸고 UUID claim과 attempts+1을 저장합니다.

**함수·상태:** `start_attempt`

**동작과 경계:** 요청·claim·시도·목표와 결과 폴더를 묶은 별도 시도 JSON을 만들며 기존 시도를 덮지 않습니다.

**함수·상태:** `record_model_failure`

**동작과 경계:** running 시도를 model_failed로 남기고 batch를 collecting으로 돌립니다. 오류 원문·시도 횟수는 보존합니다.

**함수·상태:** `store_result`

**동작과 경계:** 보고서 SHA·manifest SHA·모델 SHA와 batch 결합을 확인하여 complete 시도 결과를 원자 저장합니다.

**함수·상태:** `restore_claim`·`complete_training`

**동작과 경계:** 저장된 complete 결과를 검증하여 소유권과 완료 상태를 복구합니다. 완료 결과가 있는 시도를 무조건 재학습하지 않습니다.


`_atomic_write`는 UTF-8·LF·NaN 금지 JSON을 임시 파일에 쓰고 flush/fsync 후 교체합니다. 상태·시도 파일의 심볼릭 링크를 거부합니다. `_result`는 BTC·SOL·ETH·XRP·DOGE 다섯 시장의 후보 수, `cuda:` 장치, 준비 참, 목표 이상의 고유 적재/검증 바이트를 대조합니다. `promoted`는 학습 완료와 별도 bool로 기록합니다.

#### LEVEL 4 · 정체 원인

#### LEVEL 4 · 연구 요청·저장·실패 복구

`validate_config`는 `active`·`continuous`·`state_path` 외 설정을 거부하고 두 플래그는 정확한 bool을 요구합니다. 기본값은 `active=false`, `continuous=false`, `state_path=4차/work/research_control.json`입니다. 경로는 프로젝트의 `4차/work` 안 JSON으로 제한하고, 비활성 상태의 연속 연구는 거부합니다. `continuous` 코드 분기가 존재해도 이 차수의 두 트랙 계약은 초기 완료 후 명시 요청 대기입니다.

`request_increment`는 초기 학습 미완료·기존 활성 요청을 거부합니다. 요청을 받은 시점의 실제 고유 적재량을 baseline으로 읽고 2,000,000,000바이트를 더한 목표를 저장하므로, 이전 아카이브 단위 초과분을 다음 요청 분량으로 재사용하지 않습니다.

**함수·상태:** `_read`·`_validate`

**동작과 경계:** 첫 상태는 schema_version=1, bootstrap·collecting입니다. batch 필드, 비음수 정수, UTC 시각, ID·상태·완료 근거를 검증하고 JSON 중복 키를 거부합니다.

**함수·상태:** `training_lock`·상태 잠금

**동작과 경계:** 긴 적합 점유와 짧은 상태 읽기 잠금을 분리합니다. 상태 잠금은 최대30초,50ms 간격이며 학습 잠금은 비차단입니다.

**함수·상태:** `claim_training`

**동작과 경계:** collecting만 training으로 바꾸고 UUID claim과 attempts+1을 저장합니다.

**함수·상태:** `start_attempt`

**동작과 경계:** 요청·claim·시도·목표와 결과 폴더를 묶은 별도 시도 JSON을 만들며 기존 시도를 덮지 않습니다.

**함수·상태:** `record_model_failure`

**동작과 경계:** running 시도를 model_failed로 남기고 batch를 collecting으로 돌립니다. 오류 원문·시도 횟수는 보존합니다.

**함수·상태:** `store_result`

**동작과 경계:** 보고서 SHA·manifest SHA·모델 SHA와 batch 결합을 확인하여 complete 시도 결과를 원자 저장합니다.

**함수·상태:** `restore_claim`·`complete_training`

**동작과 경계:** 저장된 complete 결과를 검증하여 소유권과 완료 상태를 복구합니다. 완료 결과가 있는 시도를 무조건 재학습하지 않습니다.


`_atomic_write`는 UTF-8·LF·NaN 금지 JSON을 임시 파일에 쓰고 flush/fsync 후 교체합니다. 상태·시도 파일의 심볼릭 링크를 거부합니다. `_result`는 BTC·SOL·ETH·XRP·DOGE 다섯 시장의 후보 수, `cuda:` 장치, 준비 참, 목표 이상의 고유 적재/검증 바이트를 대조합니다. `promoted`는 학습 완료와 별도 bool로 기록합니다.

### 정체 원인

적재량 7,067,731,134바이트와 체크섬 검증량 7,832,698,113바이트는 서로 다른 지표입니다. `BTCUSDT-aggTrades-2026-02.zip`은 공식 체크섬이 일치했지만 내부에 역행·중복된 체결 블록이 있었습니다. 기존 반복 재시도가 다음 정상 아카이브 처리를 막았습니다. 이 자료를 정렬·중복 제거하여 정상 원본으로 가장하거나 50GB 목표에 포함하지 않습니다.

수정본을 연구 제어 변경과 함께 배포하려다 기존 수집기의 정체를 오래 남겼습니다. 수집기 선배포 때에는 루트에서 실행한 모듈 검사와 실제 스크립트 진입점의 모듈 경로 차이로 시작 직후 종료되는 결함도 확인했습니다. 관리 명령의 PID 반환만으로 수집 정상 동작을 판정하지 않습니다. 실제 데이터 증가와 모의매매 판단 갱신을 별도로 확인합니다.

### 연구 요청·저장·실패 복구

`validate_config`는 `active`·`continuous`·`state_path` 외 설정을 거부하고 두 플래그는 정확한 bool을 요구합니다. 기본값은 `active=false`, `continuous=false`, `state_path=4차/work/research_control.json`입니다. 경로는 프로젝트의 `4차/work` 안 JSON으로 제한하고, 비활성 상태의 연속 연구는 거부합니다. `continuous` 코드 분기가 존재해도 이 차수의 두 트랙 계약은 초기 완료 후 명시 요청 대기입니다.

`request_increment`는 초기 학습 미완료·기존 활성 요청을 거부합니다. 요청을 받은 시점의 실제 고유 적재량을 baseline으로 읽고 2,000,000,000바이트를 더한 목표를 저장하므로, 이전 아카이브 단위 초과분을 다음 요청 분량으로 재사용하지 않습니다.

**함수·상태:** `_read`·`_validate`

**동작과 경계:** 첫 상태는 schema_version=1, bootstrap·collecting입니다. batch 필드, 비음수 정수, UTC 시각, ID·상태·완료 근거를 검증하고 JSON 중복 키를 거부합니다.

**함수·상태:** `training_lock`·상태 잠금

**동작과 경계:** 긴 적합 점유와 짧은 상태 읽기 잠금을 분리합니다. 상태 잠금은 최대30초,50ms 간격이며 학습 잠금은 비차단입니다.

**함수·상태:** `claim_training`

**동작과 경계:** collecting만 training으로 바꾸고 UUID claim과 attempts+1을 저장합니다.

**함수·상태:** `start_attempt`

**동작과 경계:** 요청·claim·시도·목표와 결과 폴더를 묶은 별도 시도 JSON을 만들며 기존 시도를 덮지 않습니다.

**함수·상태:** `record_model_failure`

**동작과 경계:** running 시도를 model_failed로 남기고 batch를 collecting으로 돌립니다. 오류 원문·시도 횟수는 보존합니다.

**함수·상태:** `store_result`

**동작과 경계:** 보고서 SHA·manifest SHA·모델 SHA와 batch 결합을 확인하여 complete 시도 결과를 원자 저장합니다.

**함수·상태:** `restore_claim`·`complete_training`

**동작과 경계:** 저장된 complete 결과를 검증하여 소유권과 완료 상태를 복구합니다. 완료 결과가 있는 시도를 무조건 재학습하지 않습니다.


`_atomic_write`는 UTF-8·LF·NaN 금지 JSON을 임시 파일에 쓰고 flush/fsync 후 교체합니다. 상태·시도 파일의 심볼릭 링크를 거부합니다. `_result`는 BTC·SOL·ETH·XRP·DOGE 다섯 시장의 후보 수, `cuda:` 장치, 준비 참, 목표 이상의 고유 적재/검증 바이트를 대조합니다. `promoted`는 학습 완료와 별도 bool로 기록합니다.

**거부 조건:** [`not self.settings["active"]`](../../4%EC%B0%A8/research_control.py#L129)

**오류 메시지:** 명시 요청 연구가 활성화되지 않았습니다

**거부 조건:** [`path.is_symlink()`](../../4%EC%B0%A8/research_control.py#L139)

**오류 메시지:** 연구 기록의 심볼릭 링크는 허용하지 않습니다

**거부 조건:** [`self.path.is_symlink()`](../../4%EC%B0%A8/research_control.py#L213)

**오류 메시지:** 연구 상태의 심볼릭 링크는 허용하지 않습니다

**거부 조건:** [`batch["id"] != batch_id or batch["status"] != "training" or batch["claim"] != claim`](../../4%EC%B0%A8/research_control.py#L287)

**오류 메시지:** 현재 활성 학습의 소유권과 다릅니다

**거부 조건:** [`record["phase"] not in {"running", "model_failed", "complete"}`](../../4%EC%B0%A8/research_control.py#L334)

**오류 메시지:** 연구 시도 단계가 잘못됐습니다

**거부 조건:** [`(record["phase"] == "model_failed" and not isinstance(record["error"], str))                 or (record["phase"] != "model_failed" and record["error"] is not None)`](../../4%EC%B0%A8/research_control.py#L336)

**오류 메시지:** 연구 시도 오류 근거가 단계와 다릅니다

**거부 조건:** [`path.is_symlink() or not path.is_file()`](../../4%EC%B0%A8/research_control.py#L353)

**오류 메시지:** 미확인 연구 시도입니다. 소유권을 보존하고 복구를 차단합니다

**거부 조건:** [`not isinstance(batch, dict) or set(batch) != BATCH_KEYS`](../../4%EC%B0%A8/research_control.py#L175)

**오류 메시지:** 연구 batch schema가 잘못됐습니다

**거부 조건:** [`any(type(batch[key]) is not int or batch[key] &lt; 0                    for key in ("baseline_bytes", "target_bytes", "attempts"))`](../../4%EC%B0%A8/research_control.py#L183)

**오류 메시지:** 연구 용량·시도 횟수는 비음수 정수여야 합니다

**거부 조건:** [`status not in {"collecting", "training", "completed"}                     or (index &lt; len(state["batches"]) - 1 and status != "completed")                     or (batch["last_error"] is not None and not isinstance(batch["last_error"], str))`](../../4%EC%B0%A8/research_control.py#L193)

**오류 메시지:** 연구 batch 상태가 잘못됐습니다

**거부 조건:** [`state["batches"][0]["status"] != "completed"`](../../4%EC%B0%A8/research_control.py#L243)

**오류 메시지:** 초기 학습 완료 전에는 추가 연구를 요청할 수 없습니다

**거부 조건:** [`state["batches"][-1]["status"] != "completed"`](../../4%EC%B0%A8/research_control.py#L245)

**오류 메시지:** 이미 활성 연구 요청이 있습니다

**거부 조건:** [`type(baseline) is not int or baseline &lt; state["batches"][-1]["target_bytes"]`](../../4%EC%B0%A8/research_control.py#L248)

**오류 메시지:** 현재 실제 고유 적재량이 유효하지 않습니다

**거부 조건:** [`batch["id"] != batch_id or batch["status"] != "collecting"`](../../4%EC%B0%A8/research_control.py#L296)

**오류 메시지:** 활성 연구 batch가 아닙니다

**거부 조건:** [`self.attempt_path(batch).exists() and self.read_attempt(batch)["phase"] == "complete"`](../../4%EC%B0%A8/research_control.py#L306)

**오류 메시지:** 완료 결과를 학습 실패로 되돌릴 수 없습니다

**거부 조건:** [`not isinstance(value, str) or not value or Path(value).is_absolute() or "\\" in value`](../../4%EC%B0%A8/research_control.py#L326)

**오류 메시지:** 연구 시도 산출물 경로가 잘못됐습니다

**거부 조건:** [`not target.is_relative_to(self.root / "work") or target == self.root / "work"`](../../4%EC%B0%A8/research_control.py#L329)

**오류 메시지:** 연구 시도 산출물이 work 경계를 벗어났습니다

**거부 조건:** [`record[key] is not None and (not isinstance(record[key], str) or not re.fullmatch("[a-f0-9]{64}", record[key]))`](../../4%EC%B0%A8/research_control.py#L332)

**오류 메시지:** 연구 이전 산출물 식별자가 잘못됐습니다

**거부 조건:** [`any(record[key] is not None for key in ("report", "report_sha256", "manifest_sha256", "model_sha256"))`](../../4%EC%B0%A8/research_control.py#L348)

**오류 메시지:** 미완료 시도에 완료 결과가 섞였습니다

**거부 조건:** [`self.attempt_path(current).exists()`](../../4%EC%B0%A8/research_control.py#L369)

**오류 메시지:** 기존 연구 시도 기록을 덮어쓸 수 없습니다

**거부 조건:** [`record["phase"] != "running"`](../../4%EC%B0%A8/research_control.py#L378)

**오류 메시지:** 실행 중인 시도의 결과만 저장할 수 있습니다

**거부 조건:** [`record["phase"] != "running"`](../../4%EC%B0%A8/research_control.py#L390)

**오류 메시지:** 완료 저장 실패를 모델 실패로 기록할 수 없습니다

**거부 조건:** [`current["status"] != "collecting" or record["phase"] != "complete"`](../../4%EC%B0%A8/research_control.py#L402)

**오류 메시지:** 복구할 완료 시도의 소유권이 아닙니다

**거부 조건:** [`evidence["verified_archive_bytes"] &lt; evidence["ingested_archive_bytes"]`](../../4%EC%B0%A8/research_control.py#L429)

**오류 메시지:** 검증되지 않은 적재 자료입니다

**거부 조건:** [`record["phase"] != "complete" or digest(report) != record["report_sha256"]`](../../4%EC%B0%A8/research_control.py#L446)

**오류 메시지:** 내구성 있는 완료 결과와 제어 상태가 다릅니다

**거부 조건:** [`batch["attempts"] &lt; 1 or not isinstance(batch["run"], str) or not batch["run"]                         or type(batch["promoted"]) is not bool or batch["claim"] is not None`](../../4%EC%B0%A8/research_control.py#L199)

**오류 메시지:** 학습 완료 근거가 잘못됐습니다

**거부 조건:** [`any(batch[key] is not None for key in ("run", "completed_at", "promoted"))`](../../4%EC%B0%A8/research_control.py#L203)

**오류 메시지:** 미완료 batch에 완료 근거가 있습니다

**거부 조건:** [`type(baseline) is not int or baseline &lt; previous["target_bytes"]`](../../4%EC%B0%A8/research_control.py#L277)

**오류 메시지:** 현재 실제 고유 적재량이 유효하지 않습니다

**거부 조건:** [`type(evidence[key]) is not int or evidence[key] &lt; target`](../../4%EC%B0%A8/research_control.py#L427)

**오류 메시지:** 학습 자료의 적재 목표를 충족하지 못했습니다

**거부 조건:** [`batch["attempts"] &lt; 1 or not isinstance(batch["claim"], str)                             or not re.fullmatch("[a-f0-9]{32}", batch["claim"])`](../../4%EC%B0%A8/research_control.py#L206)

**오류 메시지:** 학습 소유권이 잘못됐습니다

**거부 조건:** [`batch["claim"] is not None`](../../4%EC%B0%A8/research_control.py#L209)

**오류 메시지:** 대기 batch에 학습 소유권이 있습니다

## 제약과 문제 해결

**상황:** 연구가 대기함
