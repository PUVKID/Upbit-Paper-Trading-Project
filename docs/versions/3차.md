현행 3차는 원격 커밋 `efd88ce80887dc64fc1166415ac90944feed429f`의 수집·특징·관리·설정·계약·안내 7개 파일입니다. 공통 엔진은 루트 `engine.py`, 활성 설정은 루트 `engine-config.json`, 검사는 루트 `tests/test_external_*.py`를 참조합니다. 3차 폴더만으로 구성된 독립 실행 환경이 아닙니다.

원격 구현은 고유 아카이브50GB의 다운로드·SHA검증·분봉 집계와 준비조건을 확인한 뒤 GPU학습을 연결합니다. 기존 모의계좌와 별도의 수집기를 다루며 원격 기록은50GB확보·신규모델성적을 완료로 보고하지 않습니다. 전체 파일과 실제 수정은 [원격 기준892→efd 차이](../revision-audit/3%EC%B0%A8-%EC%9B%90%EA%B2%A9%EB%B3%80%EA%B2%BD.md)에서 확인합니다.

13:38초기본의30GB목표와 이후 원격50GB구현을 구분합니다. 초기6개원문과 안내는 [초기부분 보존](3%EC%B0%A8-%EC%B4%88%EA%B8%B0%EB%B6%80%EB%B6%84.md#reading-level-1)에 그대로 남겼고 기존 `3차/연결부`·`검사` 경로도 유지했습니다. 이 초기경로는 현행 루트 코드의 대체 실행본이 아닙니다.

CLI는 명령어와 옵션을 입력해 프로그램을 실행하는 방식입니다. CSV는 값을 쉼표로 나눈 표 파일입니다. 체크섬은 받은 바이트가 형식상 손상되지 않았는지 대조하는 값입니다. 모의 운용은 계산상 계좌와 거래를 다루므로 실제 계좌 체결과 구분합니다.

입력 — 시세·호가·완료 분봉·외부 아카이브·연구 설정

처리 — 검증·저장 → 특징 준비·연구 → 정책 평가 → 모의체결·화면

출력 — 자료 준비 상태·연구 지표·모의계좌 장부·대시보드
