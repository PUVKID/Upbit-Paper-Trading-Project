- 공식 Windows 회귀: 종료 0,17.953초. 정의된 212 검사 중 Windows 선언 생략 5개.
- 공식 정적 검사:81개, 종료 0,1.641초.
- 독립 Linux 신규 검사:10개 통과,3.329초.
- 입력 불변·범위 정리 보충 검사:2개 통과.
