# 로컬 1차·2차 보존 범위

기존 보존 대응표에서 1차·2차 원본의 존재를 확인했습니다. 개인 운영자료가 함께 들어 있는 이전 압축 묶음은 원본 그대로 로컬에 보존하며 공개하지 않습니다. 해당 원자료의 세부 차이 전체를 검증했다는 주장은 하지 않습니다.

번호 없는 기존 공개 기본·GPU 개선 기록을 임의로 1차·2차에 대응시키지 않습니다. 이 안내는 제외 범위와 비교 한계를 밝히는 문서이며, 비공개 원본을 공개한 대체물이 아닙니다. 현재 공개 가능한 3차·4차 코드와 문서의 실제 차이는 각 변경 기록에서 확인할 수 있습니다.
