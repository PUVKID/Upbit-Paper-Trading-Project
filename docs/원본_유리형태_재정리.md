# 원본 유리 형태 재정리

2026-10-28 사용자는 장치 부품을 자세히 보이는 방향을 거부하고 처음 선택한 시안의 형태를 아름답게 유지하라고 정정했습니다. 실제 3D·단계 점등 요구는 그대로이며 PNG 평면으로 되돌리지 않습니다.

원본의 구조는 얇은 세 겹 유리 공간과 낮은 은색 받침, 안쪽 작은 GPU 표식·돋보기·문서, 가는 연결 흐름입니다. 큰 냉각팬·노출 핀·계단형 유리 바닥은 제거하고 GPU는 작은 글자 표식으로 표현합니다. 준비 기어·평가 렌즈·서버는 상자보다 작게 줄이고 천천히 움직입니다. 유리 자체가 그림자를 크게 만드는 부자연스러움은 투명 재질의 그림자 투사를 끄고 낮은 불투명 받침과 작은 내부 형상에만 그림자를 남겨 줄입니다.

코인명은 원본처럼 밝은 유리 위 어두운 글씨입니다. 글꼴 로드 후 명판을 재생성합니다. 모션·빛은 실제 학습 단계에만 대응하며 표시용 단계 순환과 성과 생성은 없습니다. 단계 태그는 원본에 명시된 둥근 형태와 작은 폭을 재현합니다. 나머지 UI·원시 기록·테마·모바일·모의계좌는 유지합니다.

수용 기준은 기능 검사 외에 동일한 1468×1071 원본과 실제 캡처를 나란히 열어 유리 외피·작은 상징물 비율·단계 위치·그림자·글자·여백을 대조하는 것입니다. 시각 요구는 단순 메시 개수로 판정하지 않습니다. 이전 차수 웹은 보존자료 압축본으로 보존하고 운영 경로는 하나만 유지합니다.
