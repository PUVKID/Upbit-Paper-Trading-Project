# 비용 차감 수익 연구와 거래 장부 진단

## 현재 상태

10차는 9차 이후 승인한 모델 개선을 유한 연구로 실행한 차수입니다. **실제 실행은 종료 코드0, 적합30회·완료30회, 전 모델 `cuda:0` 및 저장/재로드 검증 완료입니다. 신규 후보는 후속 평가의 거래 수·순수익 조건을 충족하지 못해 미채택했습니다.** 적합 성공과 거래 우위는 다릅니다. 최종 검증과 원격 반영은 별도 영수증으로 관리하며 GPU 성과와 구분합니다. 수익·정확도100%·낙폭10% 이내·운용 적용을 보장하지 않습니다.

기존 시세·가중치·모의계좌와 이전 차수를 보존합니다. 자동 학습 중지 표식을 삭제하지 않고, 별도 명시 허용을 받은 10차 연구만 유한하게 실행하는 구조입니다. 무제한 재학습 재개나 실제 주문 허용이 아닙니다.

## 무엇을 바꾸나요

- **계좌 위험 경계:** 사용자 선택인 균형형·최대 낙폭 목표 10%를 신규 매수 차단과 연결합니다. 기존 청산·손절은 유지하고, 복원·날짜 변경·모델 변경으로 차단 상태를 임의 해제하지 않습니다. 갭·추가 하락·비용 때문에 실제 낙폭이 목표를 넘을 수 있으며 손실 상한 보장이 아닙니다.
- **진입과 청산 근거:** 진입 당시 모델·context와 청산 당시 판단을 분리합니다. 새 실제 호가 기록은 원호가·관측 시각과 나이·위험 평가 가격 출처를 결합합니다. 과거 미기록은 미상이며 현재 모델로 역귀속하지 않습니다.
- **읽기 전용 장부 진단:** 수수료 포함 원가를 매도 수량 비율로 차감합니다. 부분매도·재진입·미청산 포지션과 현금·원가·실현손익을 대조하며 FIFO로 추정하지 않습니다. 이력이 잘렸거나 대조가 맞지 않으면 `incomplete`, 잘못된 체결 자료는 `rejected`로 표시합니다.
- **유한 수익 예측 연구:** 업비트 완료 OHLCV의 9개 시간봉에서 특징을 준비하고 다음 봉 체결 기준 비용 차감 수익·분위수 후보를 비교합니다. 외부 50GB 전체 자료를 학습하는 연구가 아니며, 기존 외부 자료의 확보량을 이번 학습량으로 표시하지 않습니다.

## 연구와 평가 계약

실제 실행은 2개 시간순 구간·5개 시장·시장별 3모델, 합계30회 적합을 완료했습니다. 90일 학습 창·적합당 최대150라운드·튜닝 구간 조기 종료를 사용했으며 실제 boosting round는21~150입니다. 코인·fold별 실제 학습 행은24,780~25,237행입니다. 업비트 완료 OHLCV의9개 시간봉을 사용했고 외부50GB 자료는 이번 학습에 사용하지 않았습니다. 운영 관측의 실행 구간은 UTC18:27:51~18:30:41, 약170초이며 검증된 산출물 파일은85개입니다. 실제 설정 anchor는 `2026-10-31T08:00:00Z`입니다.

학습·튜닝·정책 선정·후속 평가를 분리하고 라벨 전체 기간의 경계 겹침을 제거합니다. 이미 소비한 평가 노출을 보호하고, 후속 평가 결과로 정책을 다시 고르지 않습니다. 현금·단순 추세·비교 가능한 기존 모델을 동일 진입 기회·비용·위험 조건으로 비교합니다. 기존 모델의 학습 노출이 겹치면 독립 비교라고 부르지 않습니다. 후보는 자동 승격하지 않습니다.

실제 호가 없는 과거 평가에서 스프레드나 정확한 슬리피지 손익을 만들지 않습니다. 장부의 `fill_price_pnl`은 순실현손익에 배분된 진입·청산 수수료를 더한 체결 가격차이며, 스프레드와 시장 변동으로 임의 분해하지 않습니다. 수수료와 비용 차감 라벨을 이중 차감하지 않습니다.

## 검사와 남은 확인

실제 자료 사전 점검에서는 5개 시장·9개 시간봉의 유효 자료를 확인했습니다. 시장별 이력 시작 시점은 2017년 또는 2021년 등으로 다르며, 자료 존재·유효성 확인은 전체 이력의 학습 소비나 후보 성과 검증을 의미하지 않습니다.

장부 진단의 순수 대역 회귀 23개가 통과했습니다. 부분매도·평균원가·재진입·원가 및 현금 불일치·누락 매수·수치와 시간순 검증·개인 필드 제외·호가 완결성·안정 읽기·출력 경계를 검사한 구현자 직접 결과입니다. 실제 누적 장부 진단은 특정 현재 모델의 성적이 아닙니다.

초기 전체 보충 실행475개 PASS·30.543초와 후속478개 PASS·30.489초는 각각30초 예산을 초과했습니다. 이후479개 PASS·22.487초·28개skip·종료코드0으로 시간 예산을 충족했고, 최종 직접 전체 실행은 **480개 검사PASS·24.698초·28개skip·종료코드0**입니다. 앞선 초과·실패 이력은 비공개 원문에 보존합니다.

전체 실행의 PASS와 시간 예산 충족은 skip된 경로의 실행이나 독립 승인까지 의미하지 않습니다. 최종 독립 검증·원격 반영은 별도 영수증으로 관리하고, 실제GPU 적합·후속 수익·매매 채택과 구분합니다.

별도 GUI 검사에서는 대역 상태8개와 캔버스 픽셀 검사8개 PASS가 보고됐습니다. 94개 mesh 장면의 PC·모바일·모션·테마 확인이며, 모델 적합·수익·후속 평가 검증이 아닙니다. 검사 원문과 화면 증거는 비공개로 보존합니다.

## 기존 누적 계좌 진단

읽기 전용 JSON 진단에서 현금·수량·원가·실현손익 대조가 일치했습니다(`reconciled=true`). 다음은 그 관측 시점의 기존 누적 장부 집계이며 이후 장부는 계속 변할 수 있습니다. **10차 신규 후보의 수익 또는 특정 현재 모델의 성적이 아닙니다.**

| 항목 | 관측 집계 |
| --- | ---: |
| 매도 체결 이벤트 | 35건, 모두 DOGE |
| 순실현손익 양수 / 음수 이벤트 | 1건 / 34건 |
| 순실현손익 | -440,917.75원 |
| 위 매도에 배분한 진입·청산 수수료 | 43,529.44원 |
| 수수료를 더한 체결 가격차 손익 | -397,388.31원 |

금액은 공개용 집계로 소수 둘째 자리까지 반올림했습니다. 매도 이벤트 수는 부분청산을 포함할 수 있어 독립 왕복 거래 수나 모델 승률로 해석하지 않습니다. 과거 71개 이벤트의 모델 메타데이터는 모두 미기록이므로 현재 모델에 귀속할 수 없습니다. 과거 호가 부재로 체결 가격차를 스프레드·시장 변동으로 나누거나 정확한 슬리피지 손익을 분리하지 않습니다. 개인 계좌 원문·이벤트별 기록은 공개하지 않습니다.

사전 독립 검토에서 확인한 호가 시각 기록 완결성과 실제 적합 호출 수의 내구성·비교 진입 마스크를 보완했습니다. 보완 후 독립 사전 검토를 거쳐 연구 실행과 실제 적합을 완료했으며 실행 완료가 최종 검증·공개 반영 영수증을 대신하지 않습니다. 과거 실패 원문은 비공개로 보존하며 이후 성공으로 덮어쓰지 않습니다.

추가 독립 검토에서는 불완전한 진입 context를 청산 시 다시 정제하면서 `partial_invalid`가 `recorded`로 바뀌는 귀속 문제를 확인했습니다. 기존 `invalid / partial_invalid` 상태를 보존하고 두 경우 모두 `entry_context_invalid=true`, 잘못된 진입의 flat `entry_model_run=None`을 유지하도록 보완했습니다. 관련 집중 회귀17개 GREEN이 보고됐으며, 이를 최종 독립 승인이나 실제 GPU 실험 완료로 확대하지 않습니다.

## 실제 연구 결과와 미채택

[공개 집계 JSON](실험결과.json)의 `review.eligible=false`, `promotion=false`, `candidate_ready=false`를 확인했습니다. 기각 사유는 fold별 거래 부족(`insufficient_fold_trades`), 총 청산 거래 부족(`insufficient_total_closed_trades`), 양수가 아닌 fold 수익(`non_positive_fold_return`)입니다. 두 fold 모두 최종 선정 정책은 현금 보유입니다.

후속 평가에서 신규 `plain / uncertainty / selected`는 두 fold·기본/2배 비용 모두0거래·순수익0%·관측 MDD0%였습니다. 이는 노출 없는 현금 정책의 결과로, 거래 우위나 낙폭10% 목표를 검증한 성과가 아닙니다.

| fold | 비교 대상 | 비용 | 순수익률 | 거래 수 |
| --- | --- | --- | ---: | ---: |
| 1 | 신규 plain / uncertainty / selected | 1배·2배 | 0% | 0 |
| 2 | 신규 plain / uncertainty / selected | 1배·2배 | 0% | 0 |
| 1 | 단순 추세 | 1배 | -3.75632% | 144 |
| 1 | 단순 추세 | 2배 | -3.81247% | 96 |
| 2 | 단순 추세 | 1배 | -3.38267% | 115 |
| 2 | 단순 추세 | 2배 | -3.98338% | 88 |
| 1 | 기존 모델, 후향 진단 | 1배 | +0.68186% | 6 |
| 1 | 기존 모델, 후향 진단 | 2배 | +0.53065% | 6 |
| 2 | 기존 모델, 후향 진단 | 1배 | +0.37101% | 20 |
| 2 | 기존 모델, 후향 진단 | 2배 | -0.12923% | 20 |

현금 기준선도 두 fold·두 비용 조건에서0거래·0수익입니다. 비율은 JSON 원값에100을 곱해 반올림했으며 정책 선정 실험과 위 후속 평가를 합산하지 않습니다.

후속0거래를 신호 자체의 부재로 해석하지 않습니다. 첫 fold의 plain 정책 선정 실험은 최소값0 / 0.0005 / 0.001에서 각각12거래·-0.29141%, 7거래·-0.16772%, 1거래·-0.26488%였습니다. 비용 차감 우위가 확인되지 않은 실험을 억지로 매매 정책에 채택하지 않았습니다. 둘째 fold의 일부 plain 정책 실험은11거래·+0.13266%로 `eligible=true`였지만 MDD는 약0.28992%였습니다. 선정 점수 `net_return - 0.5 × MDD`는 `0.0013266337944870532 - 0.5 × 0.0028992335735867902 = -0.0001229829923063419`로 현금의0보다 낮아 최종 현금 정책이 선택됐습니다. 정책 실험의 양수를 후속 성과나 최종 채택으로 바꾸지 않습니다.

두 fold의 학습 구간은 겹치며 이번 연구는 독립 미사용 최종 시험이 아닙니다. 기존 모델 결과는 평가 기간의 학습 노출 때문에 `retrospective_diagnostic`이며 새 미사용 성능이나 신규 후보와의 독립 우열 검증으로 해석할 수 없습니다. 과거 실제 호가 부재에 따른 스프레드·정확한 체결비용 한계, 작은 청산 표본, 실제 운용과 후향 비교의 차이를 유지합니다. 기존 누적 계좌 진단도 위 신규 후보 성과와 합치지 않습니다.
