# 10차 거래 모델 재정비 계약

## 요구와 범위

2026-11-03 사용자는 제안한 변경과 필요한 보완을 적용해 다시 진행하도록 요청했고, 새 GPU 실험 및 기존 데이터 활용·정리를 재량으로 허용했습니다. 유효 자료·기존 가중치·장부·실패 이력을 보존하고 근거 없는 전체 삭제는 하지 않습니다. 9차 중지 표식은 유지하며 별도의 명시적인 유한 연구 실행만 허용합니다. 기존 무제한 자동 학습을 재개하는 요청으로 확대하지 않습니다.

모의 원금은 합계1,000만원, 대상은 BTC·SOL·ETH·XRP·DOGE, 업비트 공개 시세 기반 현물 모의매매입니다. 실제 주문·인증키·외부 알림·강제 거래·공매도·레버리지는 사용하지 않습니다. 기존 대시보드의 배치·테마·글꼴을 임의로 바꾸지 않습니다.

## 확인한 문제와 대응

- 같은 자료의 반복 추가학습에서 학습 손실 감소와 튜닝 손실 증가가 관측됐습니다. 새 연구는 유한 후보·조기 종료·시간순 분리로 실행하고 과거 재사용 평가를 독립 최종 시험으로 표현하지 않습니다.
- 기존 진입 비용 필터의 라벨 임계값은 기대이익이 아닌 대리 예산입니다. 새 후보는 다음 봉 체결 기준의 비용 차감 수익을 직접 예측하고 불확실성을 별도 비교합니다. 모델 확률을 원화 기대수익으로 오인하지 않습니다.
- 선택한 최대 낙폭 목표10%가 계좌 전체 신규 매수 차단 조건으로 구현되지 않았습니다. 관측 시점의 평가액과 고점 대비 손실을 기준으로 신규 매수만 차단하고 기존 손절·청산을 유지합니다. 한도를 넘지 않는다는 보장은 없으며 갭·체결비용·보유자산의 추가 하락은 발생할 수 있습니다.
- 과거 거래에는 진입 당시 모델·확률·호가 이력이 부족합니다. 기록된 수수료·평균 원가·실현손익은 대조하되 알 수 없는 과거 원인을 만들지 않고 이후 거래의 근거를 기록합니다.

## 구현과 검증

1. 기존 엔진에 낙폭 제한과 거래 근거 기록을 추가합니다. 일일 손실 제한과 별도로 복원·날짜 변경 뒤에도 중지 상태를 유지하며, 미래 종가로 과거 진입을 차단하지 않습니다.
2. 순수 JSON 장부 분석기는 평균원가·부분체결·재진입·미청산 자산을 대조하고 비용을 이중 차감하지 않습니다. 누락·불일치는 명시하며 진단 원문은 비공개로 둡니다.
3. GPU XGBoost 수익·분위수 후보를 최대2개 시간순 구간, 시장별3모델, 합계30회 이내의 적합으로 비교합니다. 기본90일 학습 창·조기 종료·최대150라운드를 사용합니다. 입력 준비와 학습·평가 시간을 분리합니다.
4. 보호 시험 구간과 이미 소비한 최종 시험을 학습·선정·평가에서 제외합니다. 정책은 정책 선정 구간에서만 정하며 후속 평가 결과로 임계값을 다시 고르지 않습니다. 기존 모델의 학습 노출과 후향 비교 한계를 표시합니다.
5. 현금·단순 추세·비교 가능한 기존 모델, 기본 비용과 비용 증가 조건을 동일 평가 행에서 비교합니다. 실제 호가가 없는 과거 구간의 스프레드·체결 성과는 미검증으로 남깁니다.
6. CUDA 사전 검사·첫 업데이트 전 검사·반복 검사와 가중치 저장/재로드 대조를 유지합니다. CPU 학습 대체·평가 실패 숨김·무한 재시도는 허용하지 않습니다. 후보는 자동 승격하지 않습니다.
7. 실패 원문·실제 검사·독립 검토·다음 차수 변경 기록·전체 비교·GitHub 원격 확인을 남깁니다. 새 논문·원고는 없으며 코드·검사·연구 문서만 공개합니다. 데이터·모델·계좌·운영 원문·개인 지침은 비공개입니다.

## 성공의 의미

코드 검사 통과·GPU 적합 완료·연구 후보 준비·모의 수익·매매 적용은 서로 다른 상태입니다. 기준 미달이면 미달로 표시하고 기존 모델을 보존합니다. 정확도100% 또는 최강 거래 모델·수익·낙폭 목표 달성을 보장하지 않습니다.
