# 두 트랙 연구 계약

최신 사용자 정정: 최초 외부 고유 아카이브 50,000,000,000바이트를 수집·검증·적재한 뒤 학습을 한 회차 완료합니다. 이후에는 자동으로 다음 연구를 시작하지 않습니다. 사용자가 명시 요청할 때마다 그 시점의 실제 적재량을 기준으로 새 고유 자료 2,000,000,000바이트를 추가 수집하고 학습을 한 회차 진행합니다. 현재 정정 자체는 첫 2GB 추가 수집 요청이 아닙니다.

초기 학습 이전 2GB 요청과 실행 중 중복 요청은 거부합니다. 마지막 아카이브 단위로 목표를 초과한 양을 다음 요청의 2GB로 재사용하지 않습니다. 압축해제·DB·복제 용량으로 목표를 채우지 않습니다. 준비 실패와 학습 실패는 완료로 기록하지 않으며 재시작해도 완료 이력과 활성 요청을 보존합니다.

학습 한 회차는 기존 다섯 시장의 후보 학습·평가·승격 검토가 정상 반환한 경우입니다. 후보가 기존 승격 기준에 미달해 채택되지 않은 경우도 학습 수행 완료와 구분해 기록합니다. 학습 완료가 정확도·수익·모델 승격 성공을 뜻하지 않습니다. 기존 시간순 분리·잠금 시험·비용·승격·GPU 전용 조건을 완화하지 않습니다.

정상 완료 산출물 저장과 연구 제어 상태 기록 사이에 중단돼도 같은 연구를 다시 적합하지 않아야 합니다. 완료 산출물을 연구 요청·시도 소유권·목표에 결합하고 재시작 시 검증해 남은 저장 절차만 복구합니다. 미완료·다른 요청·내용이 바뀐 결과를 완료로 복구하지 않습니다. 검증 실패는 원문과 함께 드러내며 임의 완료 표시나 무조건 재학습으로 숨기지 않습니다.

모의매매는 별도 트랙입니다. 연구 자료 수집·학습·사용자 요청 대기와 관계없이 기존 검증 모델의 업비트 현물 모의매매 판단과 청산을 계속합니다. 추론에 필요한 업비트 및 외부 최신 시세 갱신은 유지하되 이를 새 연구 요청이나 자동 재학습으로 취급하지 않습니다. 원금과 계좌·체결 이력은 보존하며 실제 주문·외부 알림·강제 거래를 추가하지 않습니다.

현재 3차의 ‘50GB 이후 업비트 200개씩 자동 재학습’ 정책은 이번 계약으로 대체됩니다. API 요청당 200개 제한과 기존 자료의 중복 없는 저장은 그대로이며, 자동 재학습 허용을 뜻하지 않습니다.

성공 기준: 초기 50GB 미달 정규 연구 적합 0회, 준비 후 학습 정확히 한 회차, 완료 후 정규 연구 적합 0회·자료 대량 수집 중지, 명시 요청 뒤 실제 현재 적재량+2GB 동결, 실패/재시작/중복 요청 경계, 모의매매 독립 실행, 정직한 대기 표시를 검증합니다. 운영 자료는 Linux에서만 접근합니다. 별도 GPU 기능 검사와 통제된 작은 자료·대역을 사용한 소프트웨어 검사는 정규 연구 및 실제 50GB 학습 완료와 구분하며 성과로 집계하지 않습니다.
