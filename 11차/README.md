# TimesFM 사전학습 모델의 Zero-Shot 비교

## 목적과 현재 상태

10차의 비용 차감 수익 후보가 미채택된 결과를 보존하고, 공개 사전학습 모델의 실제 예측과 거래 비용 이후 성과를 별도 연구로 비교합니다. 첫 후보는 Apache-2.0 모델인 Google `timesfm-2.5-200m-pytorch`입니다. 모델 이름이나 일반 벤치마크 성적을 코인 수익성으로 바꾸지 않습니다.

**유효 GPU 실험10회를 완료한 뒤 중지했습니다.** 총56,320처리창은 실제 시장 예측56,300창과재로드제어probe20개입니다. 후속validation의28,150방향표본에서 표본 가중 방향 일치율49.136767%입니다. 사전학습 가중치를 그대로 사용하는 zero-shot 추론으로 추가학습 적합은0회이며 신규 후보는 미채택·가상투자 미적용입니다. 방향 일치율은 거래 승률·수익률이 아닙니다. 10차의30회 적합 결과와 이번11차의 GPU 추론을 구분합니다.

## 비교 계약

**완료 구성은 원래7회 + 원계획의 남은2회 + 자료 부족 대체1회입니다.** 원래10개anchor를 전부 완료한 것이 아닙니다. 8회차 원기간 `2025-01-03T08:00:00Z`는 후속 평가의5시장 공통 연속 문맥이100개 미만이라 GPU 추론0회로 실패했습니다. [실행 보완 계획](실행보완계획.json)에 따라 기존7회를 재실행하지 않고 원계획Jan10·Jan17과 대체Nov8을 완료했습니다. 대체는 가격·수익이 아닌 자료 부족에 근거하며 원6시간deadline·평가 기준을 유지했습니다. 화면과 사용 검증 대상은PC입니다.

- 완료된 과거512개5분봉을 문맥으로 사용하고12봉을 예측합니다. 최대6,000개 예측 창으로 제한하며 실제 사용 표본 수와 제외 사유를 별도로 기록합니다.
- 정책 선정과 후속 평가를 시간순으로 분리합니다. 현금·추세·비교 가능한 기존 모델에 같은 진입 기회, 비용1배·2배와 낙폭 조건을 적용합니다. 예측 오차와 가상 거래 성과를 구분합니다.
- 기존 연구에 노출된 기간의 결과는 후향 비교이며 독립 미사용 최종 시험이 아닙니다. 보호 시험과7차 평가 구간을 유지하고 미래 가격·미완성봉·평가 결과를 정책 선정으로 되돌려 쓰지 않습니다.
- 라이선스·고정 모델 revision·파일 해시·실제 CUDA 실행을 확인합니다. CPU 전처리·검사는 허용하지만 모델 추론을 CPU 성공으로 대체하지 않습니다. 기존 실행 환경을 덮어쓰지 않습니다.
- TimesFM3.0 다운로드 가중치의 비상업·비운영 제한 때문에 자동 대체하지 않습니다. 다른 모델·추론 설정으로 바뀌면 동일 실험의 성과로 합치지 않습니다.

## 운영과 후속 연구

기존5코인 현물 모의매매·시세 수집·가상 원금·기존 모델을 유지합니다. 별도 연구 후보는 미검증 상태로 승격하거나 실제 주문에 적용하지 않습니다. 기존 중지 표식을 단순 제거하거나6차의 무조건 반복 적합을 재개하지 않습니다.

이번 허용 범위인 유효10회를 마친 뒤11차STOP을 생성하고 자동 반복은일시정지 상태입니다. 기존6차pause·7/8차STOP과 기존5코인 모의매매를 유지하며 새 연구를 자동 재개하지 않습니다. 실험마다 범위·평가 노출·실행 예산을 구분하고 각 검증된 변경 묶음의 로컬 기록·독립 검토·GitHub 원격 확인을 별도 관리합니다. 동일 실험 재실행·강제 거래·미검증 승격은 하지 않습니다. 수익·정확도100%·낙폭10% 이내·최강 모델을 보장하지 않습니다.

## 관측 결과의 범위

별도 `pretrained_benchmark` 상태를 API whitelist와 기존 화면 흐름에 연결합니다. GPU 예측 창 수와 적합0회·운용 미적용을 구분하며 기존10차 결과를 유지합니다. 관련 API4개·Node20개PASS는 통제된 상태 표시 검사이며 실제 가중치 로드·GPU 추론·수익 검증을 의미하지 않습니다.

PC 실제 완료 화면에서는94mesh·비어 있지 않은 캔버스·가로 넘침없음·JavaScript오류0과 “평가 완료 · 미적용” 제목을 확인했습니다. 별도Node20개PASS와 구분하며 화면·운영 검증 원문은 비공개로 보존합니다. 학습은waiting_request, 자동 반복은일시정지이고 기존 모의매매·실제 주문금지 경계를 유지합니다. 모의 판단 횟수는 실행 상태 관측이며 신규 후보의 수익·채택 증거가 아닙니다.

모델 revision은 `1d952420fba87f3c6dee4f240de0f1a0fbc790e3`이며10회 모두GPU 확인·추가학습0회입니다. 회차 경과시간 합은833.041977초이고 원suite 시작부터 보완 완료까지의 벽시계 시간은1,003.807609초입니다. 두 시간은 정의가 다르며 GPU 커널의 순수 실행 시간으로 표현하지 않습니다. [공개 집계](실험결과.json)는10개manifest의 전체 산출물inventory·해시·재로드 수치 재계산과 기존7개결과 불변 대조를 거쳐 생성됐습니다. 해당 검증 원문은 비공개이며 최종 독립 검증과 원격 반영은 별도 영수증으로 관리합니다.

`candidate_ready=false`, `promotion=false`로 신규 후보는미채택·운용 미적용입니다. 사전학습 모델의 해당 기간 노출 여부가 미확인이므로 독립 미사용 최종 시험이 아니며, 기존 모델 비교도 학습 노출에 따른후향진단입니다. 과거 실제 호가의 추가비용은미상(`null`)입니다. 방향 일치율·가격 오차·거래 성과·실제 금융 적용을 서로 구분합니다. 현금·추세·기존 모델의 비용1배/2배별 수익·MDD·거래 수는 공개JSON에 보존합니다.

방향 일치율49.136767%는60분 뒤 종가 변화 방향의 일치율입니다. 기존XGBoost의3클래스 분류 정확도나 거래 승률과 같은 지표가 아닙니다. 예측 지평이 겹치는 표본을 독립 시행으로 가정하거나 이 표본 수만으로 통계적 우위를 주장하지 않습니다.

독립 읽기 전용산출물대조는76개PASS·230개artifact해시·재로드수치·기존7회산출물불변을확인했습니다. 현재운용모델포인터의모델ID일치는확인했지만실행직전포인터바이트스냅샷이없으므로포인터바이트불변은주장하지않습니다. 직접검사506개·총28.188초의30초capture, 정적검사159개PASS·Node20개PASS·PC실제QA와최종독립영수증·원격반영을구분합니다.

## 실행 CLI

PC의 기존Linux 컨테이너 프로젝트root에서 검증된Torch/CUDA Python을 사용합니다. 아래는 명령 형식이며 이번10회가 끝난 현재 상태에서 재실행하라는 지시가 아닙니다. 이후 새 실행은 명시적 사용자 허용과 새 식별자가 필요합니다. 기존suite 예약은 거부하며 `--resume` 옵션·자동 재시도는 없습니다. 11차STOP과 기존 중지 표식을 이 문서에 따라 삭제하지 않습니다.

```sh
python -B -X utf8 11차/benchmark_suite.py --suite NEW_APPROVED_SUITE
python -B -X utf8 11차/pretrained_benchmark.py --once --run NEW_APPROVED_RUN --config 11차/benchmark-config.json
```

suite는실행전예약·기존예약거부·실패재시도금지·STOP전용그룹중지를 적용합니다. 자료부족 보완은 [고정된보완계획](실행보완계획.json)에 기록한별도실행이며 원7회를다시돌리거나원6시간예산을초기화하는resume가아닙니다.
