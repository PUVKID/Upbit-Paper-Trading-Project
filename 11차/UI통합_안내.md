# 11차 대시보드 통합

11차의 연구 결과와 현재 조회 화면을 같은 차수에서 읽도록 통합했습니다. **디자인만 별도 차수로 게시하지 않습니다.** 기존 실험 설명·집계·원래 전체 비교·미채택·STOP은 그대로 보존합니다.

| 자료 | 확인할 내용 |
| --- | --- |
| [원래 실험 설명](README.md) | TimesFM zero-shot 비교, 추가 학습 0회·후향 한계·미채택 |
| [실제 대시보드 파일](대시보드/) | HTML·JavaScript·3D·CSS·폰트·서버·시작 진입점의 보존 사본 |
| [UI 전용 전체 비교](UI_전체비교.md) | 이번 공개 파일·안내·탐색 변경과 바이너리 크기·해시 |
| [원래 연구 전체 비교](전체비교.md) | 기존 10차 이후 연구 코드 비교, 이번에 덮어쓰지 않음 |

아래 다섯 설명은 같은 통합을 서로 다른 출발점에서 설명합니다. 대시보드 안의 README는 통합 준비 시점의 문서를 원문 보존한 것입니다. 실제 화면 교체 확인과 현재 제약은 이 안내에서 구분합니다.

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

대시보드는 저장된 연구·시장·가상계좌 정보를 보여 주는 화면입니다. 화면을 정리했다고 새 모델이 더 좋은 성적을 낸 것은 아닙니다. 11차의 기존 예측 결과와 거래 손실·미채택은 바뀌지 않았습니다.

| 확인할 것 | 실제 상태 | 주의 |
| --- | --- | --- |
| 화면 위치 | E11의 대시보드 파일로 통합 | 보존 이력 폴더에서 실행하지 않음 |
| 표시 | 다섯 코인·3D·밝은/어두운 테마·굵은 한글 글꼴 유지 | 예시 숫자·새 성과를 만들지 않음 |
| 연결 | 화면 문서 응답 200, 상태 조회 503 확인 기록 | 화면이 열리는 것과 시세를 읽는 것은 다름 |

현재 조회 화면은 8881 주소를 승계한 하나의 UI입니다. 옛 화면을 선택지나 별도 포트의 병행 기본값으로 남기지 않습니다. 연결 실패는 정상 시세가 아니며, 11차 STOP과 자동 반복 일시정지·실제 주문 금지 경계를 유지합니다.

<a id="reading-level-2"></a>
## LEVEL 2 - Explorer

Astryx는 화면 요소의 색·간격·테두리·조작 상태를 일관되게 연결하는 디자인 체계입니다. 기존 DOM과 데이터 처리를 유지하면서 공식 중립 CSS·생성 토큰·화면 어댑터를 함께 사용합니다.

| 입력 | 연결 | 출력·경계 |
| --- | --- | --- |
| 기존 HTML·JS·3D·폰트 | 실제 파일을 E11 대시보드에 복사 | 기능·선택·필터·정보 보존 |
| 기존 두 테마 팔레트 | Rust 생성 CSS와 어댑터 로드 | 밝은/어두운 화면, 새 Rust 실행 아님 |
| D 원본 상태 relay | 읽기 전용 `/api/status` 전달 | 연결 실패는 HTTP 503으로 유지 |

실행 위치가 E11로 바뀌어도 원래 D 데이터 relay 의존은 남습니다. 프로젝트 전체를 E로 이전한 상태가 아닙니다. 새 연구·수집·컨테이너·거래를 시작하거나 화면 변경을 수익 개선으로 설명하지 않습니다.

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner

현재 화면의 cwd는 `E:/2026/Upbit 5-Coin Project/11차/대시보드`이며 진입점은 그 폴더의 `server.py --port 8881` 또는 `시작.ps1`입니다. 시작 스크립트는 개인 홈에서 기존 Codex runtime Python을 찾으며 인증·새 환경 설치·기존 프로세스 종료를 수행하지 않습니다.

| 순서 | 확인 | 해석 |
| --- | --- | --- |
| 파일 | 이 저장소의 `11차/대시보드` 27파일 | 원본과 같은 바이트로 보존한 사본 |
| 운영 | E11 서버로 8881 교체·GET 확인 기록 | 이미 실행 중인 포트를 중복 기동하지 않음 |
| 응답 | `/` 200·17,585바이트, 테마/어댑터 200 | 상태 API의 503과 구분 |
| 재현 조건 | D relay와 공통 E Rust 환경 | 공개 다운로드만으로 전체 환경 재현 가능하다고 하지 않음 |

공통 Rust 실행 파일·Cargo 소스·lock·공식 패키지 설치 환경은 이 묶음에 없습니다. 생성된 CSS는 포함하지만 재생성에는 별도 의존성과 `work` 출력 위치 준비가 필요합니다. 비공개 원본 목록에 의존하는 검사.py는 복제하지 않았습니다. 기존 45항목 UI 검사와 생성 해시는 재사용했습니다.

<a id="reading-level-4"></a>
## LEVEL 4 - Advanced

화면 파일 24개와 통합 안내·시작 진입점 3개를 실제 E11에서 보존했습니다. `server.py`의 `ROOT/web`는 현재 대시보드를 가리키며, 기본 포트 8881과 D 원본 relay 호출은 바꾸지 않았습니다.

| 경계 | 구현 | 검증·제약 |
| --- | --- | --- |
| UI | 공식 CSS·테마 CSS·기존 어댑터와 실제 DOM | 기존 UI 독립 PASS·45항목 재사용 |
| 서버 | loopback·허용 GET·변경 요청 거부 | 기존 읽기 경계 근거 재사용 |
| 데이터 | `D:/2026/Upbit 5-Coin Project/tools/docker_control.py` | D 원본 의존 유지, SQLite 직접 개방 추가 없음 |
| 공개 | 실행 소스 27파일 불변, 공개 안내·링크·비교 추가 | 개인 지침·work·evidence·계좌·인증 제외 |

D의 기존 root/web는 현재 역할을 임의 확정해 삭제하거나 교체하지 않았습니다. 구 UI 병행 운영을 권장하는 의미도 아닙니다. 공개 준비에서는 제품 모듈·UI·Rust를 실행하지 않고 공개 파일 분류·문서 링크·목록만 확인합니다.

## LEVEL 5 - Expert

서버 소스 SHA-256은 `d2a1fb0179c2a653bcc865db3d8d96708a8dcd6aa8dd710c84112f200689d3df`, 생성 테마 CSS는 `443e52130566ff1cb9f86165448abcd5a60bfa43bcbc0459ed171494f71d265f`입니다. 실제 E11 파일·공개 사본·비공개 snapshot의 27파일을 별도로 대조합니다. 11차 원래 실험 결과의 분모·수치·실패를 UI 통합의 결과로 재분류하지 않습니다.

| 근거 | 확인 범위 | 대신하지 않는 것 |
| --- | --- | --- |
| 기존 UI45·독립 PASS | 테마·폭·조작부·읽기 경계 | 이번 공개 안전성·읽기 수준 의미 검토 |
| Rust 생성 기록 | light/dark 기존 실호출과 CSS 해시 | 새로운 Rust 빌드 재현·가속·성능 향상 |
| 화면 교체 인계 | 실제 E11 8881, 문서·테마·어댑터 200, 상태503 | 유효 시세·계좌 연결 성공 |
| 공개 UI 전용 비교 | 새 파일·문서·공백·주석·바이너리 해시 | 원래11차 연구 전체 비교의 대체 |

실제 브라우저 표시는 이번 교체 인계에서 확인하지 못했습니다. 기존 Three.js 경고·물리 터치·모든 브라우저 미확인 한계는 유지합니다. 독립 공개 검토·최종 커밋·푸시·원격 일치가 완료되기 전 이 후보를 공개 완료로 보고하지 않습니다. 보존 이력과 실패·미게시 초안은 로컬에 남기며 별도 디자인 차수를 새 연구 차수로 게시하지 않습니다.
