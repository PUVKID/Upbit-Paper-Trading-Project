# Windows 원자 저장의 한정 재시도

## 후속 보완 범위

11차 GPU 실험 10회 완료 이후 발견된 Windows 원자 JSON 저장 오류를 보완합니다.

실제 회귀 중 `WinError 5`가 재발했으며, Windows에서 열려 있는 읽기 핸들을 이용한 통제 probe는 오류를 재현하고 핸들을 닫은 뒤 저장 성공을 확인했습니다.

이 통제 결과만으로 자연 발생 잠금의 주체를 확정하지 않습니다.

보완 대상은 `7차/shadow_research.py`의 `atomic_json`과 `tests/test_foundation_atomic_io.py`입니다.

Windows에서만 `winerror`5·32·33에 한정해 **총 5 시도**, 시도 사이 대기 10 +20 +30 +40ms로 총 100ms의 유한 재시도를 적용했습니다.

Linux의 단일 replace·디렉터리 fsync와 기존 예외 동작은 유지합니다.

다른 오류는 재시도하지 않으며 지속 오류의 원문을 전파하고 옛 payload·임시 payload를 보존합니다.

무한 재시도·검증 비활성화·계좌 재작성·실제 주문·디자인 변경은 포함하지 않습니다.

## 실험과 코드 보완의 구분

기존 11차는 zero-shot GPU10회·추가 학습 0회·미채택·실행 후 중지 상태입니다.

이번 저장 보완으로 모델을 재학습하거나 기존 10회를 새 코드로 다시 실행한 것이 아닙니다.

기존 결과 JSON의 SHA256 `cdf9e88b57a687d7cba90b3cab7e0f71c9891082d4e3f2725649d2da6c6aab54`을 보존하며 GPU 성과·후향 비교 한계·금융 운용 미적용은 바꾸지 않습니다.

신규 6개 회귀는 RED 이후 GREEN을 확인했으며 Windows 실제 읽기 핸들 해제 뒤 성공하는 경로를 포함합니다.

전체 512개 검사·26.595초 PASS(skip28), 정적 163개 PASS가 보고됐습니다. skip된 경로의 실행이나 최종 독립 승인·원격 반영까지 의미하지 않습니다.

통제 probe·회귀·전체 실행과 최종 검증·원격 반영은 각각 별도 근거·영수증으로 관리합니다.

## 보존과 전체 비교

원격에 추가된 11차 상세 안내 68 행과 기존 문서 내용을 보존하고 이 보완 안내만 추가합니다.

원래 [11차 실험 전체 비교](전체비교.md)는 후속 문서 변경에서도 수정하지 않습니다.

전체 비교 파일 157,219 바이트와 내부 raw patch156,058바이트는 다른 범위입니다.

새 코드·검사·문서의 주석·공백을 포함한 후속 차이는 기준 `b3ce566df3b63e62285e1e0ee329c5a283f1e5a3`의 [원자 저장 후속 전체 비교](원자저장_전체비교.md)에서 구분합니다.

같은 11차의 보완이며 새 12차를 만들지 않습니다.

공개 7차 소스의 기존 정제된 설명을 보존하고 한정된 코드 수정만 반영합니다. 원본 7차 파일 전체를 공개 소스에 복사해 덮어쓰지 않습니다. 백업·잠금 probe·환경·운영·검증 원문, 가중치·모델·계좌·개인정보·인증 자료는 비공개입니다. 새 논문·원고가 없어 PDF를 만들지 않습니다.
