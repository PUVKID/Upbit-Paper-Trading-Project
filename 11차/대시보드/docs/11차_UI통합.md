후속 디자인 이력의 파일을 현재 11차에 실제 복사했습니다. 실행 시 과거 상위 번호 폴더를 읽거나 거기로 이동하는 래퍼가 아닙니다. 화면 내부에 해당 번호 문구가 없으므로 기능·DOM·표·필터·3D·테마를 수정하지 않았습니다. 서버 구현도 기본 포트가 이미 8881이어서 수정하지 않았습니다.

## 단일 화면 교체 원칙

현재 화면은 `E:/2026/Upbit 5-Coin Project/11차/대시보드`의 읽기 전용 서버가 8881을 승계하는 구성입니다. 부모 담당자가 기존 화면 프로세스의 commandline을 대조한 뒤 읽기 전용 화면만 교체합니다. 이 담당자는 프로세스 조회를 통한 교체 판단·종료·기동을 하지 않습니다.

보존 이력의 구 UI는 선택 메뉴·별도 포트·병행 기본값으로 제공하지 않습니다. D의 기존 `root/web`는 역할과 사용 여부를 임의 확정해 삭제하거나 교체하지 않습니다. 이를 별도 UI 운영 대상으로 안내하지도 않습니다. 원래 백엔드·컨테이너·모델·수집·실주문·계좌·전략·인증은 이번 범위가 아닙니다.

## 재사용 근거와 새 확인

기존 45항목 UI 조작부 검사와 독립 UI PASS, Rust light/dark 실호출·생성 CSS 해시를 로컬 비공개 인계에서 연결합니다. 구현과 자산이 같은 바이트인지를 확인하되 동일 UI/full 검사는 반복하지 않습니다. 이 대시보드에는 비공개 원장 목록·검사.py·evidence·work·라우팅 상태를 복제하지 않았습니다.

새 확인은 복사 파일의 크기·SHA-256, HTML/CSS의 실제 정적 자산 연결, 높은 차수 실행 파일 참조 부재, E11 시작 경로와 8881 인자로 한정합니다. 이전 API 503은 실패 관측이며 새 경로의 실제 GET은 부모가 확인해야 합니다. 이전 검증을 현재 시세 연결 성공·전체 연구 성능·모든 브라우저 무결함으로 확대하지 않습니다.

E11의 이 폴더는 대시보드 통합본일 뿐입니다. D11의 실험 원본·학습 코드·STOP·모델·결과는 그대로 남아 있으며, E11의 연구 코드 전체 준비나 전체 이전을 완료한 것으로 표시하지 않습니다. 기존 실험 README는 변경하지 않았습니다.
