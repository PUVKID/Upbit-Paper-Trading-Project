Astryx 화면을 11차의 실제 대시보드 파일로 통합했습니다. **표시 계층의 통합이며 11차 연구 결과의 변경은 아닙니다.** 실험 원본 README·학습 코드·STOP·결과는 수정하거나 복제하지 않았습니다.

| 구성 | 실제 위치·역할 | 경계 |
| --- | --- | --- |
| 현재 화면 | 이 폴더의 `web/` | 보존 이력 폴더를 참조 실행하지 않음 |
| 읽기 전용 서버 | 이 폴더의 `server.py` | loopback `127.0.0.1:8881`, 기존 상태 조회만 전달 |
| 시작 진입점 | [시작.ps1](시작.ps1) | 이 폴더를 cwd로 사용, 기존 프로세스를 종료하지 않음 |
| 테마 | 보존된 공식 CSS·Rust 생성 CSS·화면 어댑터 | 새 Rust 생성·빌드 없이 기존 생성 해시 재사용 |

## 시작과 교체

**현재 UI 진입점은 이 E11 대시보드 하나입니다.** 구 UI를 선택지나 병행 기본값으로 운영하지 않습니다. 부모 담당자가 기존 8881 읽기 전용 화면의 commandline을 확인한 뒤 이 경로의 서버로 교체합니다. 실행 중인 8881 서버가 남아 있다면 이 시작 명령을 중복 실행하지 않습니다.

기동 담당자가 사용할 cwd는 `E:/2026/Upbit 5-Coin Project/11차/대시보드`입니다. 준비된 Python에서 실행할 인자는 다음과 같습니다.

```powershell
python -B -X utf8 server.py --port 8881
```

또는 이 폴더의 `시작.ps1`을 사용합니다. 스크립트는 사용자 홈의 기존 Codex runtime Python을 확인하고 위 서버를 실행합니다. Python 설치·컨테이너 기동·학습·수집·실주문·다른 프로세스 종료는 수행하지 않습니다. 이 통합 담당자는 실제 기동을 실행하지 않았으며 부모의 교체·GET 확인이 남아 있습니다.

주소는 `http://127.0.0.1:8881/`입니다. 화면 문서 HTTP 200과 `/api/status` HTTP 503은 다른 상태입니다. 상태 조회의 503을 정상 시세나 계좌 연결 성공으로 표시하지 않습니다.
