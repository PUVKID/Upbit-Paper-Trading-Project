# 11차 사전 학습 모델 비교

## 범위

2026-11-03 최신 재개 범위는 사전에 고정한 10개 anchor에서 각 1회, 합계 10회의 사전 학습 모델 비교 실험으로 한정합니다.

첫 단계는 zero-shot 추론이며 추가 학습 적합은 0회입니다. 10회 뒤 중지하며 자동 반복은 일시 정지를 유지합니다.

이전의 중단 전 계속 반복 방침을 이번 유한 범위로 대체하고, 더 이른 사용자 중단 요청을 우선합니다.

실행·평가·성능은 실제 관측 전에 완료로 기록하지 않습니다.

대상은 PC이며 각 검증된 변경 묶음은 로컬 기록·독립 검증·GitHub 원격 확인을 구분해 관리합니다. 최종 검증과 원격 반영은 별도 영수증으로 관리하며 GPU 성공과 구분합니다. 동일 실험 중복 실행·무검증 승격·억지 거래·실제 주문은 하지 않습니다.

첫 후보는 Google의 Apache-2.0 `timesfm-2.5-200m-pytorch`입니다.

TimesFM 3.0의 다운로드 가중치는 비상업·비운영 제한이 있어 자동 대체하지 않습니다.

라이선스·고정 revision·실제 장치·파일 해시를 확인합니다.

모델 이름이나 일반 예측 벤치마크를 코인 수익성으로 바꾸지 않습니다.

## 평가

10개 anchor는2024-11-15부터2025-01-17까지 주 간 간격으로 사전 고정합니다.

각 실험은 정책 선정 2일·후속 평가 2일, 완료된 512개 5분 봉 문맥·12 봉 지평·최대 6,000개 예측 창을 사용하며 suite 전체 실행 시간 상한은 6시간입니다.

결과를 본 뒤 anchor를 바꾸거나 성공한 구간만 골라 10회를 채우지 않습니다.

대상 기간의 비교는 후 향 연구이고 사전 학습 가중치의 해당 기간 노출 여부는 미확인입니다.

이를 독립 미사용 최종 시험으로 표시하지 않습니다.

확정 suite 파일은 `11차/benchmark_suite.py`, `11차/suite-config.json`, `tests/test_benchmark_suite.py`입니다.

실제 수행 수·자료 준비 상태·모델 로드·GPU 추론·평가 완료는 별도 근거로 구분합니다.

초기 준비 시점 GPU0과2026-10-31 단일 준비의 시간대 처리 실패·DOGE 연속 512 봉 문맥 부족은 원문을 보존합니다.

최종 유효 10회는 원 7 +원 계획 잔여 2 +자료 부족 대체 1이며 학습적 합 0·추론 완료·미채택을 구분합니다.

원래 08의 Jan3는 공통 문맥 100개 미만·GPU0으로 실패해 [실행보완계획](실행보완계획.json)에 따라 Nov8로 대체했고 기존 7회를 재실행하거나 원 6시간 deadline·평가 기준을 바꾸지 않았습니다.

원래 10anchor 전부 완료라고 표시하지 않으며 자료 미준비를 성공·0 수익 평가로 바꾸지 않습니다.

먼저 사전 학습 가중치의 추가 학습 없는 예측을 검사합니다.

이는 새 자료를 추가 학습했다는 의미가 아닙니다.

완료된 과거 512개 5분 봉 문맥, 12 봉 지평과 최대 6 천 개 예측 창으로 제한합니다.

정책 선정과 후속 평가를 분리하고 현금·추세·기존 모델에 같은 진입 기회와 비용 1 배·2 배 및 낙폭 기준을 적용합니다.

기존 연구에 노출된 기간의 비교는 후 향 연구이며 독립 최종 시험이 아닙니다. 보호 시험과 7차 평가 구간은 유지합니다. 예측 오차, 가상 거래 수익, GPU 실행 성공과 모델 채택은 각각 별개입니다. 후보의 자동 적용은 하지 않습니다.

## 운영

기존 데이터·모델·가상 계좌를 보존합니다. 6차의 무조건 반복 학습과 7·8차의 중지 표식은 단순 제거하지 않으며 새 연구 트랙에서 진행합니다.

기존 5 코인 현물 모의 매매와 시세 수집은 독립 유지합니다.

실제 적합·모델 추론은 CUDA에서만 수행하고 CPU 전 처리·검사는 허용합니다.

다른 연구의 프로세스·환경을 수정하지 않습니다.

이번 10회 허용을 기존 6차 pause 또는 7·8차 STOP 해제나 무제한 연구 재개로 해석하지 않습니다.

고정 anchor·실행 수·단계·실패·중단을 구분해 기록하며 결과가 없는 데 반복 횟수나 성과를 채워 쓰지 않습니다.

추가 suite 소스·설정·회귀는 실제 파일과 계약을 대조해 확정하고 결과 집계는 실제 자료가 있을 때만 공개 목록에 추가합니다.

유효 10회 완료 후 11차 STOP·자동 반복 일시 정지와 기존 중지 표식을 유지합니다.

결과는 [공개집계](실험결과.json)와 [회차별설명](README.md)에 연결하며 사전 학습 기간 노출 미확인·후향비교·예측지평중첩·실호가 비용 한계를 유지합니다.

최종 검증·원격 반영은 별도 영수증으로 관리하고 이 계약을 새 실험 재개 허용으로 해석하지 않습니다.

공개 자료는 코드·집계·변경 설명입니다. 가중치·DB·계좌·인증 정보·운영 원문은 비공개입니다. 10% 낙폭 목표·수익·정확도 100%·최강 모델을 보장하지 않습니다.
